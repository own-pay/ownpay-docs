In this tutorial you will build a webhook receiver that listens for `payment.completed` events from OwnPay and updates your order database. By the end you will have a production-ready endpoint in PHP or Node.js.

## What you will build

A single endpoint (`/webhooks/ownpay`) that:

1. Verifies the HMAC-SHA256 signature
2. Parses the event payload
3. Updates the order status in your database
4. Returns the correct HTTP response codes

## Prerequisites

- An OwnPay instance with a webhook endpoint configured in **Developers → Webhooks**
- A webhook signing secret (shown when you create the endpoint)
- PHP 8.1+ or Node.js 18+ with Express

<Steps>

### Create the webhook endpoint in OwnPay

1. Log in to your OwnPay admin panel
2. Navigate to **Developers → Webhooks**
3. Click **Add Endpoint**
4. Enter your URL: `https://yourapp.com/webhooks/ownpay`
5. Select at minimum the `payment.completed` event
6. Click **Save** and copy the **Webhook Signing Secret**

<Note>
OwnPay only sends webhooks to HTTPS URLs. Use [ngrok](https://ngrok.com/) for local development: `ngrok http 8080`.
</Note>

### Build a PHP receiver

Save this as `webhooks/ownpay.php` on your server:

```php
<?php
// webhooks/ownpay.php

$secret = getenv('OWNPAY_WEBHOOK_SECRET');
$rawBody = file_get_contents('php://input');
$signature = $_SERVER['HTTP_X_OWNPAY_SIGNATURE'] ?? '';
$timestamp = (int) ($_SERVER['HTTP_X_OWNPAY_TIMESTAMP'] ?? 0);

// 1. Reject stale events (older than 5 minutes)
if (abs(time() - $timestamp) > 300) {
    http_response_code(403);
    echo json_encode(['error' => 'Timestamp too old']);
    exit;
}

// 2. Verify HMAC-SHA256 signature - see /api/webhooks
$expected = 'sha256=' . hash_hmac('sha256', $rawBody, $secret);
if (!hash_equals($expected, $signature)) {
    http_response_code(401);
    echo json_encode(['error' => 'Invalid signature']);
    exit;
}

// 3. Parse and route the event
$event = json_decode($rawBody, true);
if (!$event) {
    http_response_code(400);
    echo json_encode(['error' => 'Invalid JSON']);
    exit;
}

$eventType = $event['event'] ?? '';
$data = $event['data'] ?? [];

// 4. Handle the event
try {
    match ($eventType) {
        'payment.completed' => handlePaymentCompleted($data),
        'payment.failed'    => handlePaymentFailed($data),
        'refund.issued'     => handleRefundIssued($data),
        default             => log("Unhandled event: {$eventType}"),
    };
} catch (\Throwable $e) {
    // Log the error but return 500 so OwnPay retries
    error_log("Webhook error: {$e->getMessage()}");
    http_response_code(500);
    echo json_encode(['error' => 'Internal error']);
    exit;
}

// 5. Acknowledge success
http_response_code(200);
echo json_encode(['received' => true]);

// --- Handler functions ---

function handlePaymentCompleted(array $data): void
{
    $orderId = $data['metadata']['order_id'] ?? null;
    if (!$orderId) return;

    // Idempotency: skip if already processed
    $order = Db::query("SELECT status FROM orders WHERE id = ?", [$orderId])->fetch();
    if ($order && $order['status'] === 'paid') return;

    Db::query("UPDATE orders SET status = 'paid', paid_at = NOW() WHERE id = ?", [$orderId]);
    // Fulfill the order (send confirmation email, etc.)
}

function handlePaymentFailed(array $data): void
{
    $orderId = $data['metadata']['order_id'] ?? null;
    if (!$orderId) return;
    Db::query("UPDATE orders SET status = 'failed' WHERE id = ? AND status = 'pending'", [$orderId]);
}

function handleRefundIssued(array $data): void
{
    $orderId = $data['metadata']['order_id'] ?? null;
    if (!$orderId) return;
    Db::query("UPDATE orders SET status = 'refunded' WHERE id = ?", [$orderId]);
}
```

### Build a Node.js receiver

Install dependencies and create the endpoint:

```bash
npm install express raw-body
```

```javascript
// webhooks/ownpay.js
import express from 'express';
import crypto from 'crypto';
import fs from 'fs';

const app = express();
const SECRET = process.env.OWNPAY_WEBHOOK_SECRET;

// IMPORTANT: parse as raw buffer for signature verification
app.use('/webhooks/ownpay', express.json({
  verify: (req, _res, buf) => { req.rawBody = buf; }
}));

app.post('/webhooks/ownpay', async (req, res) => {
  const signature = req.headers['x-ownpay-signature'];
  const timestamp = parseInt(req.headers['x-ownpay-timestamp'], 10);
  const rawBody = req.rawBody.toString('utf8');

  // 1. Reject stale events
  if (Math.abs(Date.now() / 1000 - timestamp) > 300) {
    return res.status(403).json({ error: 'Timestamp too old' });
  }

  // 2. Verify signature - see /api/webhooks
  const hmac = crypto.createHmac('sha256', SECRET).update(rawBody).digest('hex');
  const expected = `sha256=${hmac}`;

  if (!crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(signature))) {
    return res.status(401).json({ error: 'Invalid signature' });
  }

  // 3. Route the event
  const { event, data } = req.body;

  try {
    switch (event) {
      case 'payment.completed':
        await markOrderPaid(data.metadata?.order_id);
        break;
      case 'payment.failed':
        await markOrderFailed(data.metadata?.order_id);
        break;
      case 'refund.issued':
        await markOrderRefunded(data.metadata?.order_id);
        break;
    }
  } catch (err) {
    console.error('Webhook error:', err.message);
    return res.status(500).json({ error: 'Internal error' });
  }

  // 4. Acknowledge
  res.json({ received: true });
});

app.listen(8080, () => console.log('Webhook server listening on :8080'));
```

### Handle real events in production

When moving to production, keep these principles in mind:

- **Idempotency** - check your database state before applying changes. OwnPay may deliver the same event more than once.
- **Timeout** - respond within 10 seconds. If processing is slow, respond `200` immediately and handle asynchronously in a queue.
- **Log everything** - store the raw payload and your processing result for debugging.

### Error handling and retries

OwnPay uses your HTTP status code to decide whether to retry:

| Your response | OwnPay action |
|---|---|
| 2xx | Delivered - no retry |
| 4xx | Permanent failure - no retry (fix your code) |
| 5xx or timeout | Temporary failure - retry on schedule |

See the full retry schedule on the [Webhooks](/api/webhooks) page.

<Warning>
Never return a 5xx for validation errors (e.g. unknown event type). Return 200 and log the event - returning 5xx causes unnecessary retries.
</Warning>

</Steps>

### Security best practices

- Verify the signature on **every** request - never skip it
- Reject events with timestamps older than 5 minutes to prevent replay attacks
- Only process events you have registered for - ignore unknown event types
- Use HTTPS exclusively - OwnPay never sends webhooks to HTTP endpoints
- Keep your webhook secret in environment variables, never in code
