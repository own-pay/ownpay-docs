पेमेंट लिंक साझा करने योग्य चेकआउट URL हैं जिन्हें आप एडमिन डैशबोर्ड से बनाते हैं। ग्राहक लिंक खोलते हैं, पेमेंट तरीका चुनते हैं और भुगतान पूरा करते हैं - किसी इनवॉइस या API इंटीग्रेशन की आवश्यकता नहीं।

## पेमेंट लिंक बनाएँ {#create-a-payment-link}

1. **Payments** → **Payment Links** पर जाएँ।
2. **\+ Create Link** पर क्लिक करें।
3. विवरण भरें (नीचे विकल्प देखें)।
4. **Create Link** पर क्लिक करें।
5. लिंक सूची से साझा करने योग्य URL कॉपी करें और अपने ग्राहक को भेजें।

## लिंक विकल्प {#link-options}

| विकल्प | प्रकार | आवश्यक | विवरण |
| --- | --- | --- | --- |
| **Title** | Text | हाँ | चेकआउट पर ग्राहक को दिखाया जाने वाला नाम (उदाहरण के लिए "Consultation fee") |
| **Description** | Text area | नहीं | चेकआउट पेज पर दिखाए जाने वाले अतिरिक्त निर्देश या विवरण |
| **Amount** | Number | नहीं | निश्चित मूल्य। ग्राहक को अपनी राशि दर्ज करने देने के लिए खाली छोड़ें |
| **Currency** | Select | हाँ | बिलिंग मुद्रा (ऐसे गेटवे से मेल खानी चाहिए जो इसे सपोर्ट करता हो) |
| **Custom fields** | JSON schema | नहीं | अतिरिक्त इनपुट फ़ील्ड जिन्हें ग्राहक को भरना होगा (उदाहरण के लिए "Order ID") |
| **Max uses** | Number | नहीं | लिंक से अधिकतम कितनी बार भुगतान किया जा सकता है। `0` का अर्थ असीमित है |
| **Expires at** | Date/time | नहीं | इस तारीख के बाद लिंक स्वचालित रूप से निष्क्रिय हो जाता है |
| **Redirect URL** | URL | नहीं | सफल भुगतान के बाद ग्राहक को कहाँ भेजना है |
| **Webhook URL** | URL | नहीं | केवल इस लिंक के लिए कस्टम webhook एंडपॉइंट |

## निश्चित बनाम परिवर्तनीय राशि {#fixed-vs-variable-amount}

- **निश्चित राशि** - Amount फ़ील्ड में एक मान दर्ज करें। ग्राहक को लॉक किया हुआ मूल्य दिखता है और वह इसे बदल नहीं सकता।
- **परिवर्तनीय राशि** - Amount फ़ील्ड खाली छोड़ें। चेकआउट पेज एक इनपुट दिखाता है जहाँ ग्राहक अपनी राशि टाइप करता है। इसका उपयोग दान, टिप या लचीले सेवा शुल्क के लिए करें।

## समाप्ति और उपयोग सीमाएँ {#expiry-and-usage-limits}

एक-बार उपयोग वाले लिंक के लिए **Max uses** को `1` पर सेट करें (उदाहरण के लिए किसी विशिष्ट इनवॉइस भुगतान के लिए)। पुराने लिंक को हफ़्तों बाद उपयोग होने से रोकने के लिए **Expires at** तारीख सेट करें। जब कोई लिंक समाप्त हो जाता है या अपनी उपयोग सीमा तक पहुँच जाता है, तो ग्राहकों को "Link expired" संदेश दिखता है।

## Redirect URL {#redirect-urls}

जब ग्राहक भुगतान पूरा करता है, तो उसे आपके द्वारा कॉन्फ़िगर किए गए **Redirect URL** पर भेज दिया जाता है। OwnPay `trx_id` और `status` को query parameters के रूप में जोड़ता है ताकि आप अपनी ओर से परिणाम की पुष्टि कर सकें।

## पेमेंट लिंक एम्बेड करना {#embedding-payment-links}

आप अपनी वेबसाइट पर `<iframe>` में पेमेंट लिंक एम्बेड कर सकते हैं। चेकआउट URL को `src` attribute के रूप में उपयोग करें। सुनिश्चित करें कि आपकी वेबसाइट अपने Content Security Policy हेडर में OwnPay डोमेन की अनुमति देती है।

<Warning>
  लिंक साझा करने से पहले उसकी मुद्रा के लिए कम से कम एक पेमेंट गेटवे सक्रिय होना चाहिए। अन्यथा ग्राहकों को चेकआउट पर कोई उपलब्ध पेमेंट तरीका न होने की त्रुटि दिखती है।
</Warning>
