OwnPay एडमिन पैनल और ग्राहक-सामने वाले चेकआउट दोनों के लिए कई भाषाओं को सपोर्ट करता है। भाषा प्राथमिकताएँ व्यक्तिगत स्टाफ़ स्तर और ब्रांड स्तर पर सेट की जा सकती हैं।

## अपनी एडमिन भाषा बदलें {#change-your-admin-language}

हर स्टाफ़ सदस्य स्वतंत्र रूप से अपनी पसंदीदा एडमिन पैनल भाषा सेट कर सकता है:

1. ऊपरी-दाएँ कोने में अपने **अवतार** पर क्लिक करें
2. **My Account** चुनें
3. ड्रॉपडाउन से अपनी **Language** चुनें
4. **Save** पर क्लिक करें

पूर्ण व्यक्तिगत सेटिंग्स गाइड के लिए [मेरा अकाउंट](/hi/security/my-account) देखें।

## सिस्टम भाषाएँ प्रबंधित करें {#manage-system-languages}

सभी उपलब्ध भाषाओं को देखने और प्रबंधित करने के लिए **System \> Languages** पर जाएँ।

| कॉलम | विवरण |
| --- | --- |
| **Language** | प्रदर्शित नाम (उदाहरण के लिए, "English", "Bengali") |
| **Code** | ISO 639-1 कोड (उदाहरण के लिए, `en`, `bn`) |
| **Status** | Installed या Not Installed |
| **Brand Default** | क्या यह किसी विशिष्ट ब्रांड के लिए डिफ़ॉल्ट है |

## भाषा पैक अपलोड करें {#upload-a-language-pack}

<Steps>
  <Step>
    **Upload Language Pack** पर क्लिक करें और एक JSON फ़ाइल चुनें।
  </Step>
  <Step>
    OwnPay फ़ाइल संरचना को सत्यापित करता है और अनुवादों को इम्पोर्ट करता है।
  </Step>
  <Step>
    यदि भाषा कोड अभी मौजूद नहीं है, तो उसे स्वचालित रूप से जोड़ दिया जाता है।
  </Step>
</Steps>

### भाषा फ़ाइल फ़ॉर्मेट {#language-file-format}

भाषा फ़ाइलें dot-notation keys वाली JSON होती हैं:

```json
{
  "checkout.pay_now": "Pay Now",
  "checkout.enter_amount": "Enter Amount",
  "common.currency": "Currency"
}
```

<Info>
  अनुवादों में योगदान करने या पूर्ण भाषा पैक बनाने के मार्गदर्शन के लिए, [अनुवाद गाइड](/hi/developer/translations) देखें।
</Info>

## प्रति ब्रांड डिफ़ॉल्ट भाषा सेट करें {#set-default-language-per-brand}

Languages सूची में, किसी भी इंस्टॉल की गई भाषा के आगे **Set as Default** पर क्लिक करें। एक ब्रांड चयनकर्ता दिखाई देता है - चुनें कि यह डिफ़ॉल्ट किस ब्रांड पर लागू होगा। उस ब्रांड का चेकआउट अनुभव इस भाषा का उपयोग करेगा, जब तक कि ग्राहक का ब्राउज़र कुछ और अनुरोध न करे।

## चेकआउट भाषा का निर्धारण {#checkout-language-determination}

जब कोई ग्राहक चेकआउट पेज पर आता है, तो OwnPay इस क्रम में भाषा निर्धारित करता है:

1. **ब्रांड डिफ़ॉल्ट भाषा** - वर्तमान ब्रांड के लिए System \> Languages में सेट की गई भाषा
2. **ब्राउज़र Accept-Language हेडर** - यदि ब्रांड डिफ़ॉल्ट सेट नहीं है, तो OwnPay विज़िटर की ब्राउज़र भाषा प्राथमिकता पढ़ता है
3. **English फ़ॉलबैक** - यदि कोई मेल नहीं मिलता, तो English का उपयोग किया जाता है

<Tip>
  यदि आपका ग्राहक आधार बहुभाषी है, तो ब्रांड डिफ़ॉल्ट को सेट न करें। तब OwnPay स्वचालित रूप से हर विज़िटर की ब्राउज़र भाषा प्राथमिकता का सम्मान करेगा।
</Tip>
