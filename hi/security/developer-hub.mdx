डेवलपर हब OwnPay को बाहरी सिस्टम के साथ इंटीग्रेट करने के लिए आपका केंद्रीय कार्यक्षेत्र है। यह वेबहुक प्रबंधित करने, एंडपॉइंट का परीक्षण करने और API गतिविधि की समीक्षा करने के लिए टूल प्रदान करता है।

## वेबहुक प्रबंधन {#webhook-management}

डेवलपर हब में Webhooks टैब आपको वेबहुक एंडपॉइंट बनाने, संपादित करने और हटाने देता है। इवेंट चयन और हस्ताक्षर सत्यापन सहित पूर्ण वेबहुक सेटअप गाइड के लिए, [वेबहुक](/hi/notifications/webhooks) देखें।

## वेबहुक डिलीवरी लॉग {#webhook-delivery-logs}

हर वेबहुक डिलीवरी प्रयास यहाँ लॉग किया जाता है, चाहे वह सफल हो या विफल।

| कॉलम | विवरण |
| --- | --- |
| **Endpoint** | लक्ष्य URL |
| **Event** | वह इवेंट प्रकार जिसने डिलीवरी ट्रिगर की |
| **Status** | Success (2xx), Failed (non-2xx) या Pending (पुनः प्रयास निर्धारित) |
| **Attempts** | डिलीवरी का कितनी बार प्रयास किया गया है |
| **Timestamp** | अंतिम प्रयास कब हुआ |

पूरा अनुरोध payload, रिस्पॉन्स बॉडी और रिस्पॉन्स हेडर देखने के लिए किसी भी लॉग पंक्ति पर क्लिक करें।

<Info>
  डिलीवरी लॉग 30 दिनों तक रखे जाते हैं। स्थायी रिकॉर्ड के लिए, अपने वेबहुक एंडपॉइंट पर सर्वर-साइड लॉगिंग लागू करें।
</Info>

## टेस्ट वेबहुक {#test-webhook}

एक नमूना `payment.completed` payload भेजने के लिए किसी भी एंडपॉइंट के आगे **Test Webhook** पर क्लिक करें। यह आपके एंडपॉइंट पर एक असली HTTP अनुरोध भेजता है ताकि आप सत्यापित कर सकें:

- आपका सर्वर पहुँच योग्य है
- हस्ताक्षर सत्यापन सही ढंग से काम करता है
- आपका रूटिंग और प्रोसेसिंग लॉजिक payload को संभालता है

टेस्ट डिलीवरी डिबगिंग के लिए डिलीवरी लॉग में भी दिखाई देती है।

## API अनुरोध लॉग {#api-request-logs}

API Logs टैब आपके OwnPay API एंडपॉइंट (तीनों परतों) पर किए गए हर अनुरोध को रिकॉर्ड करता है।

| कॉलम | विवरण |
| --- | --- |
| **API Layer** | Admin, Merchant या Mobile |
| **Endpoint** | अनुरोधित URI |
| **Method** | GET, POST, PUT, DELETE |
| **Status Code** | HTTP रिस्पॉन्स स्टेटस |
| **IP Address** | अनुरोधकर्ता का स्रोत IP |
| **Timestamp** | अनुरोध कब किया गया |

एंडपॉइंट, स्टेटस कोड या तिथि सीमा के आधार पर विशिष्ट अनुरोध खोजने के लिए खोज और फ़िल्टर नियंत्रणों का उपयोग करें।

<Tip>
  API लॉग इंटीग्रेशन समस्याओं को डिबग करने के लिए उपयोगी हैं। यदि कोई थर्ड-पार्टी इंटीग्रेशन अप्रत्याशित रिस्पॉन्स की रिपोर्ट करता है, तो यह देखने के लिए API लॉग जाँचें कि OwnPay ने ठीक क्या लौटाया।
</Tip>
