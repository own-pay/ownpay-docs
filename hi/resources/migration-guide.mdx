## माइग्रेशन प्रक्रिया {#migration-process}

OwnPay एक **ऑटो-माइग्रेशन** सिस्टम का उपयोग करता है जो बूट समय पर चलता है। आपको माइग्रेशन कमांड मैन्युअल रूप से चलाने की आवश्यकता नहीं है।

### ऑटो-माइग्रेशन कैसे काम करता है {#how-auto-migration-works}

जब `Kernel::boot()` चलता है, तो यह वर्तमान स्कीमा संस्करण (`op_system_settings` में संग्रहीत) की तुलना कोड संस्करण से करता है। यदि वे भिन्न हैं, तो यह `database/migrations/` से लंबित माइग्रेशन फ़ाइलों को क्रम से निष्पादित करता है।

हर माइग्रेशन फ़ाइल एक सुरक्षित पैटर्न का उपयोग करती है:

```sql
-- Migration: 001_add_disputes_table.sql

CREATE TABLE IF NOT EXISTS op_disputes (
  id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  -- ...
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- Add column only if it does not exist
SET @dbname = DATABASE();
SET @tablename = 'op_transactions';
SET @columnname = 'dispute_status';
SET @preparedStatement = (SELECT IF(
  (SELECT COUNT(*) FROM INFORMATION_SCHEMA.COLUMNS
   WHERE TABLE_SCHEMA = @dbname AND TABLE_NAME = @tablename AND COLUMN_NAME = @columnname) > 0,
  'SELECT 1',
  CONCAT('ALTER TABLE ', @tablename, ' ADD COLUMN ', @columnname, ' VARCHAR(50) DEFAULT NULL')
));
PREPARE alterIfNotExists FROM @preparedStatement;
EXECUTE alterIfNotExists;
DEALLOCATE PREPARE alterIfNotExists;
```

इस `SHOW COLUMNS / ALTER TABLE` पैटर्न का अर्थ है कि माइग्रेशन **idempotent** हैं - उन्हें कई बार चलाना सुरक्षित है।
