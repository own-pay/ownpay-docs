लैंडिंग पेज वह सार्वजनिक पेज है जो विज़िटर्स को तब दिखता है जब वे आपके OwnPay रूट URL (उदाहरण के लिए `https://pay.example.com`) पर जाते हैं। आप इसे मार्केटिंग पेज, पेमेंट पोर्टल हब के रूप में उपयोग कर सकते हैं, या इसे पूरी तरह अक्षम कर सकते हैं।

## लैंडिंग पेज को सक्षम या अक्षम करें {#enable-or-disable-the-landing-page}

1. **Appearance** → **Landing Page** पर जाएँ।
2. **Enable Landing Page** को चालू या बंद करें।
3. अक्षम होने पर, रूट URL पर जाने वाले विज़िटर्स को एडमिन लॉगिन पेज पर रीडायरेक्ट कर दिया जाता है।

## पेज का शीर्षक और विवरण सेट करें {#set-the-page-title-and-description}

ये फ़ील्ड नियंत्रित करते हैं कि ब्राउज़र टैब और सर्च इंजन परिणामों में क्या दिखाई देता है:

| फ़ील्ड | उद्देश्य |
| --- | --- |
| **Page title** | ब्राउज़र टैब टेक्स्ट और `<title>` टैग |
| **Meta description** | सर्च परिणामों में दिखाया जाने वाला 150–160 कैरेक्टर का सारांश |
| **Meta keywords** | SEO के लिए कॉमा से अलग किए गए कीवर्ड |

## हीरो सेक्शन कॉन्फ़िगर करें {#configure-the-hero-section}

हीरो सेक्शन लैंडिंग पेज के शीर्ष पर बड़ा बैनर है:

| फ़ील्ड | विवरण |
| --- | --- |
| **Hero title** | मुख्य हेडलाइन (उदाहरण के लिए "Fast, Secure Payments") |
| **Hero subtitle** | शीर्षक के नीचे टैगलाइन |
| **CTA button text** | कॉल-टू-एक्शन बटन का लेबल |
| **CTA button URL** | बटन किस पते पर लिंक करता है |

## फ़ीचर कार्ड {#feature-cards}

क्षमताओं को उजागर करने के लिए आप हीरो के नीचे फ़ीचर कार्ड जोड़ सकते हैं:

1. **\+ Add Feature Card** पर क्लिक करें।
2. एक शीर्षक, विवरण दर्ज करें और एक आइकन चुनें।
3. हर फ़ीचर के लिए दोहराएँ।
4. **Save Settings** पर क्लिक करें।

## कस्टम HTML {#custom-html}

उन्नत कस्टमाइज़ेशन के लिए, आप लैंडिंग पेज में कस्टम HTML जोड़ सकते हैं। इसका उपयोग एम्बेडेड वीडियो, थर्ड-पार्टी विजेट या कस्टम सेक्शन जोड़ने के लिए करें। HTML पेज बॉडी के अंदर रेंडर होता है, इसलिए आवश्यकता हो तो `<style>` टैग के माध्यम से अपनी स्टाइलिंग शामिल करें।

<Warning>
  कस्टम HTML विज़िटर के ब्राउज़र में चलता है। अविश्वसनीय स्रोतों से ट्रैकिंग स्क्रिप्ट शामिल न करें, और ऐसे इनलाइन JavaScript से बचें जो पेज की मौजूदा स्क्रिप्ट से टकरा सकता है।
</Warning>

## एडमिन लॉगिन URL {#admin-login-url}

लैंडिंग पेज सेटिंग्स में **Admin Login URL Slug** भी होता है। डिफ़ॉल्ट रूप से यह `login` होता है, लेकिन स्वचालित बॉट्स से एडमिन लॉगिन को छिपाने के लिए आप इसे किसी अनोखे नाम (उदाहरण के लिए `my-secure-portal`) में बदल सकते हैं। केवल छोटे अक्षर, अंक और हाइफ़न का उपयोग करें।
