थीम आपके ग्राहकों को दिखने वाले चेकआउट पेज के लेआउट और विज़ुअल स्टाइल को नियंत्रित करती हैं। हर ब्रांड अलग थीम का उपयोग कर सकता है, इसलिए आप हर स्टोरफ़्रंट के लिए चेकआउट अनुभव को अनुकूलित कर सकते हैं।

## थीम चुनें {#select-a-theme}

1. **Appearance** → **Themes** पर जाएँ।
2. इंस्टॉल की गई थीम की सूची देखें।
3. अपनी पसंद की थीम खोजें और **Activate** पर क्लिक करें।
4. बदलाव सभी नए चेकआउट सेशन के लिए तुरंत प्रभावी हो जाता है।

## बिल्ट-इन थीम {#built-in-themes}

OwnPay एक डिफ़ॉल्ट थीम के साथ आता है जो अधिकांश उपयोग के मामलों के लिए काम करती है। यह रिस्पॉन्सिव है, लाइट और डार्क मोड को सपोर्ट करती है, और सभी आधुनिक ब्राउज़रों पर सही ढंग से रेंडर होती है।

<Note>
  फ़ॉलबैक के रूप में डिफ़ॉल्ट थीम को हमेशा इंस्टॉल रखें। यदि किसी कस्टम थीम में त्रुटि है, तो आप तुरंत डिफ़ॉल्ट पर वापस जा सकते हैं।
</Note>

## प्लगइन के माध्यम से कस्टम थीम {#custom-themes-via-plugins}

आप प्लगइन सिस्टम के माध्यम से अतिरिक्त थीम इंस्टॉल कर सकते हैं। कस्टम थीम `manifest.json` और टेम्पलेट फ़ाइलों के साथ `.zip` फ़ाइलों के रूप में पैकेज की जाती हैं।

1. **\+ Install Theme** पर क्लिक करें।
2. थीम की `.zip` फ़ाइल अपलोड करें।
3. थीम आपकी सूची में दिखाई देती है।
4. इसका उपयोग करने के लिए **Activate** पर क्लिक करें।

अपनी थीम बनाने के विवरण के लिए, [थीम डेवलपमेंट](/hi/developer/plugin-types/theme) देखें।

## प्रति-ब्रांड थीम असाइनमेंट {#per-brand-theme-assignment}

थीम ब्रांड स्तर पर असाइन की जाती हैं:

1. **People** → **Brands** पर जाएँ और किसी ब्रांड को संपादित करें।
2. **Theme** सेक्शन में, चुनें कि यह ब्रांड किस थीम का उपयोग करेगा।
3. **Save** पर क्लिक करें।

इससे आप एक ब्रांड के लिए प्रोफ़ेशनल थीम और दूसरे के लिए कैज़ुअल थीम का उपयोग कर सकते हैं।

## CSS कस्टमाइज़ेशन {#css-customization}

यदि आपको पूरा थीम प्लगइन बनाए बिना छोटे विज़ुअल बदलाव चाहिए, तो आप कस्टम CSS जोड़ सकते हैं:

1. **People** → **Brands** पर जाएँ और ब्रांड को संपादित करें।
2. **Custom CSS** टेक्स्ट एरिया में, अपने CSS नियम दर्ज करें।
3. थीम स्टाइलशीट लोड होने के बाद ये नियम चेकआउट पेज में जोड़े जाते हैं।

इसका उपयोग फ़ॉन्ट साइज़, बटन बॉर्डर रेडियस या स्पेसिंग बदलने जैसे छोटे समायोजनों के लिए करें। बड़े लेआउट बदलावों के लिए, इसके बजाय एक उचित थीम प्लगइन बनाएँ।

<Warning>
  अविश्वसनीय स्रोतों से थीम `.zip` फ़ाइलें अपलोड न करें। थीम फ़ाइलों में PHP या JavaScript हो सकता है जो आपके सर्वर पर या आपके ग्राहकों के ब्राउज़र में चलता है।
</Warning>
