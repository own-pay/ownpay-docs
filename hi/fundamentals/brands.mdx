**ब्रांड** OwnPay की मल्टी-टेनेंट आइसोलेशन की इकाई है। जब आप एक ब्रांड बनाते हैं, तो आपको एक पूरी तरह से स्वतंत्र मर्चेंट इकाई मिलती है - इसके अपने पेमेंट गेटवे, चेकआउट डोमेन, विज़ुअल ब्रांडिंग, स्टाफ़ टीम, API कुंजियाँ, ग्राहक डेटाबेस और डबल-एंट्री लेजर - जो उसी OwnPay इंस्टेंस पर मौजूद हर दूसरे ब्रांड से पूरी तरह अलग रहते हैं।

हर डेटाबेस क्वेरी सक्रिय ब्रांड के `merchant_id` तक सीमित होती है। ब्रांड A का स्टाफ़ ब्रांड B के लेनदेन, ग्राहक या सेटिंग्स नहीं देख सकता। ब्रांडों के बीच कोई डेटा लीक संभव नहीं है।

## ब्रांड बनाम प्लेटफ़ॉर्म {#brand-vs-platform}

<Columns>
  <Column>
    **प्लेटफ़ॉर्म (OwnPay इंस्टेंस)**

    - मास्टर एडमिनिस्ट्रेटर खाता
    - सिस्टम-व्यापी सेटिंग्स और प्लगइन
    - DNS और SSL प्रबंधन
    - डेटाबेस सर्वर और Redis
    - सब कुछ चलाने वाला एकल कोडबेस
  </Column>
  <Column>
    **ब्रांड (मर्चेंट टेनेंट)**

    - अलग-थलग ग्राहक और लेनदेन
    - स्वतंत्र गेटवे क्रेडेंशियल
    - अलग API कुंजियाँ और webhooks
    - कस्टम डोमेन और ब्रांडिंग
    - अपना लेजर और बैलेंस रिपोर्ट
  </Column>
</Columns>

प्लेटफ़ॉर्म इंफ्रास्ट्रक्चर है। ब्रांड उस इंफ्रास्ट्रक्चर पर चलने वाले मर्चेंट हैं।

## प्रति-ब्रांड कॉन्फ़िगरेशन {#per-brand-configuration}

हर ब्रांड स्वतंत्र रूप से नियंत्रित करता है:

| सेटिंग | विवरण |
| :-- | :-- |
| **गेटवे** | कौन-से पेमेंट प्रदाता सक्रिय हैं और उनके क्रेडेंशियल |
| **डोमेन** | कस्टम चेकआउट डोमेन (उदाहरण के लिए, `pay.acme.com`) |
| **ब्रांडिंग** | लोगो, फ़ेविकॉन, रंग योजना, चेकआउट टेम्पलेट |
| **मुद्रा और टाइमज़ोन** | रिपोर्ट के लिए डिफ़ॉल्ट मुद्रा और टाइमज़ोन |
| **स्टाफ़** | इस ब्रांड तक सीमित भूमिका-आधारित अनुमतियों वाले टीम सदस्य |
| **API कुंजियाँ** | अलग Merchant और Mobile API कीपेयर |
| **Webhooks** | स्वतंत्र webhook URL और इवेंट सब्सक्रिप्शन |
| **ईमेल** | SMTP सेटिंग्स, प्रेषक का नाम और ईमेल टेम्पलेट |

<Info>
  लेजर खाते भी सख्ती से एक ब्रांड तक सीमित होते हैं। ब्रांड A के कैश खाते का बैलेंस कभी भी ब्रांड B की रिपोर्ट में दिखाई नहीं देता।
</Info>

## सामान्य उपयोग के मामले {#common-use-cases}

| परिदृश्य | ब्रांड कैसे काम करते हैं |
| :-- | :-- |
| **SaaS प्लेटफ़ॉर्म ऑपरेटर** | हर ग्राहक कंपनी अपने चेकआउट अनुभव और लेजर के साथ एक ब्रांड है। |
| **पेमेंट एजेंसी** | हर क्लाइंट को व्हाइट-लेबल डोमेन और अलग-थलग वित्तीय डेटा के साथ एक ब्रांड मिलता है। |
| **मल्टी-एंटिटी व्यवसाय** | लेखांकन की स्पष्टता के लिए अलग-अलग डिवीज़न या सहायक कंपनियाँ अलग ब्रांड के रूप में काम करती हैं। |
