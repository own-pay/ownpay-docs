OwnPay आपके व्यवसाय और 123\+ पेमेंट प्रदाताओं के बीच स्थित है। जब कोई ग्राहक "Pay" पर क्लिक करता है, तो OwnPay पेमेंट को सही गेटवे तक रूट करता है, परिणाम को डबल-एंट्री लेजर में दर्ज करता है, और आपके एप्लिकेशन को एक webhook वापस भेजता है - यह सब आपके नियंत्रण वाले इंफ्रास्ट्रक्चर से।

## OwnPay को क्या अलग बनाता है {#what-makes-ownpay-different}

- **पूर्ण डेटा संप्रभुता के साथ सेल्फ़-होस्टेड** - आपका सर्वर, आपका डेटाबेस, आपके नियम। ग्राहक PII को रेस्ट पर AES-256-GCM से एन्क्रिप्ट किया जाता है। कोई तीसरा पक्ष आपका डेटा नहीं देखता।
- **तुरंत उपलब्ध 123\+ गेटवे** - अंतरराष्ट्रीय प्रोसेसर (Stripe, PayPal) के साथ क्षेत्रीय अग्रणी (bKash, Nagad, GCash, Razorpay, SSLCommerz), और हर रिलीज़ में और जोड़े जाते हैं।
- **OwnPay की ओर से शून्य लेनदेन शुल्क** - AGPL-3.0 के तहत लाइसेंस प्राप्त। आप केवल अपने गेटवे का प्रोसेसिंग शुल्क चुकाते हैं।
- **AGPL-3.0 लाइसेंस और हमेशा के लिए मुफ़्त** - कोई फ़ीचर प्रतिबंध नहीं, कोई लाइसेंसिंग टियर नहीं, कोई फ़ोन-होम टेलीमेट्री नहीं। पूरा सोर्स [GitHub]({{github}}) पर।
- **प्लगइन से विस्तार योग्य** - कोर कोड बदले बिना गेटवे, थीम, ऐडऑन और इंटीग्रेशन जोड़ें। 60 से अधिक हुक और एक पूर्ण इवेंट सिस्टम।
- **डबल-एंट्री लेजर** - `bcmath`-संचालित सटीकता, ब्रांड आइसोलेशन और अंतर्निहित रिकंसिलिएशन के साथ लेखांकन-स्तरीय वित्तीय ट्रैकिंग।

## OwnPay किसके लिए है? {#who-is-ownpay-for}

| दर्शक | वे OwnPay का उपयोग कैसे करते हैं |
| :-- | :-- |
| **SaaS व्यवसाय** | ग्राहक डेटा को इन-हाउस रखते हुए एक एकीकृत API के माध्यम से सब्सक्रिप्शन और एकमुश्त पेमेंट स्वीकार करें। |
| **मार्केटप्लेस प्लेटफ़ॉर्म** | मल्टी-टेनेंट पेमेंट ऑर्केस्ट्रेशन - हर विक्रेता को अलग-थलग फ़ंड और रिपोर्टिंग के साथ एक ब्रांड मिलता है। |
| **फ़्रीलांसर और एजेंसियाँ** | सेकंडों में पेमेंट लिंक बनाएँ, क्लाइंट के लिए चेकआउट को व्हाइट-लेबल करें, और लेजर में आय ट्रैक करें। |
| **एंटरप्राइज़** | ऑन-प्रिमाइसेस या प्राइवेट क्लाउड पर डिप्लॉय करें, डेटा रेज़िडेंसी आवश्यकताओं का पालन करें, और Admin API के माध्यम से इंटीग्रेट करें। |

## तकनीकी स्टैक सारांश {#technical-stack-summary}

<Columns>
  <Column>
    **रनटाइम**

    - PHP 8.3\+ (कस्टम फ़्रेमवर्क, Laravel नहीं)
    - सर्वर-साइड टेम्पलेट के लिए Twig 3
    - फ़्रंटएंड पर Vanilla JavaScript
    - सभी मौद्रिक गणनाओं के लिए `bcmath`
    - PII एन्क्रिप्शन के लिए AES-256-GCM
  </Column>
  <Column>
    **इंफ्रास्ट्रक्चर**

    - MySQL 8\+ (स्कीमा, लेनदेन, लेजर)
    - Redis (कैशिंग, सेशन, क्यू)
    - PHP-FPM के साथ Nginx या Apache
    - Docker Compose समर्थन
  </Column>
  <Column>
    **इंटीग्रेशन**

    - 3 REST API परतें (Merchant / Mobile / Admin)
    - HMAC-SHA256 webhook सिग्नेचर
    - SMS सत्यापन के लिए Android कंपैनियन ऐप
    - हुक, फ़िल्टर और इवेंट के साथ Plugin SDK
  </Column>
</Columns>
