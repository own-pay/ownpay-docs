OwnPay एक कैपेबिलिटी सिस्टम का उपयोग यह घोषित करने के लिए करता है कि एक प्लगइन क्या करता है और किन प्लेटफ़ॉर्म सुविधाओं के साथ इंटरैक्ट करता है। कैपेबिलिटीज़ `manifest.json` में स्ट्रिंग मानों के रूप में व्यक्त की जाती हैं और `OwnPay\Plugin\Capability` बैक्ड PHP enum से मैप की जाती हैं।

<Note>
  **पूर्ण-विश्वास मॉडल**: इंस्टॉल किए गए प्लगइन मालिक द्वारा अपलोड किए जाते हैं और पूर्ण एप्लिकेशन विश्वास के साथ चलते हैं। कैपेबिलिटीज़ घोषणात्मक मेटाडेटा और एक इरादा अनुबंध हैं। ये दस्तावेज़ करती हैं कि एक प्लगइन क्या करता है और UI प्रस्तुति को संचालित करती हैं; ये रनटाइम प्रवर्तन सैंडबॉक्स नहीं हैं।
</Note>

## कैपेबिलिटीज़ घोषित करना {#declaring-capabilities}

कैपेबिलिटीज़ `manifest.json` के अंदर `capabilities` ऐरे में घोषित की जाती हैं:

```json
{
  "slug": "my-plugin",
  "capabilities": ["addon", "hooks", "cron"]
}
```

एंट्रीपॉइंट क्लास पर `PluginInterface::capabilities()` मेथड को मेल खाने वाले `Capability` enum केस लौटाने चाहिए:

```php
use OwnPay\Plugin\Capability;

public function capabilities(): array
{
    return [Capability::ADDON, Capability::HOOKS, Capability::CRON];
}
```

## सुरक्षा-संबंधी टिप्पणियाँ {#security-relevant-notes}

### `db_read` / `db_write` - SQL आइसोलेशन {#db_read-/-db_write-sql-isolation}

किसी भी `op_*` टेबल पर क्वेरी, जिसका नाम `op_plugin_` से शुरू नहीं होता, `PluginSandbox::validateSql()` द्वारा ब्लॉक कर दी जाती है।

### `file_read` / `file_write` - पाथ कंटेनमेंट {#file_read-/-file_write-path-containment}

`PluginSandbox::validateFilePath()` लक्ष्य पाथ को रिज़ॉल्व करने के लिए `realpath()` का उपयोग करता है और जाँचता है कि वह प्लगइन डायरेक्टरी पाथ से शुरू होता है।

### ब्लॉक किए गए PHP फ़ंक्शन {#blocked-php-functions}

कैपेबिलिटीज़ चाहे जो हों, निम्नलिखित फ़ंक्शन तुरंत लोड विफलता का कारण बनते हैं:

| ब्लॉक किया गया फ़ंक्शन | कारण |
| --- | --- |
| `exec()` | सीधा OS कमांड निष्पादन |
| `shell_exec()` | बैकटिक-समतुल्य के माध्यम से शेल कमांड |
| `system()` | सीधे आउटपुट के साथ OS कमांड |
| `passthru()` | कच्चा OS कमांड निष्पादन |
| `popen()` | प्रोसेस पाइप ओपनर |
| `proc_open()` | पूर्ण प्रोसेस नियंत्रण |
| `pcntl_exec()` | प्रोसेस इमेज प्रतिस्थापन |
| `dl()` | डायनामिक एक्सटेंशन लोडिंग |
| `assert()` | असर्शन के माध्यम से कोड मूल्यांकन |
| `create_function()` | रनटाइम लैम्ब्डा कोड जनरेशन |
| `eval` | डायनामिक कोड मूल्यांकन |
