यह गाइड OwnPay के लिए पेमेंट गेटवे प्लगइन बनाने, इंस्टॉल करने और बनाए रखने के लिए आवश्यक हर चीज़ को कवर करती है। हर उदाहरण `modules/gateways/stripe/` पर मौजूद लाइव Stripe गेटवे इम्प्लीमेंटेशन से लिया गया है।

## गेटवे प्लगइन कैसे काम करते हैं {#how-gateway-plugins-work}

जब OwnPay बूट होता है, तो `PluginLoader::loadActive()` `modules/gateways/` को स्कैन करता है, सभी सक्रिय गेटवे डायरेक्टरी खोजता है, प्रत्येक `manifest.json` को सत्यापित करता है, हर PHP फ़ाइल को खतरनाक फ़ंक्शन के लिए टोकन-स्कैन करता है, और एंट्रीपॉइंट क्लास का इंस्टेंस बनाता है।

चूँकि एक गेटवे क्लास `PluginInterface` और `GatewayAdapterInterface` दोनों को लागू करती है, इसलिए लोडर सभी प्लगइन बूट करने के बाद स्वचालित रूप से `GatewayBridge::registerAdapter($instance)` को कॉल करता है।

```text
HTTP Request
    +-- CheckoutController / WebhookController
         +-- GatewayBridge::initiate() / verify() / refund()
              +-- GatewayAdapterInterface (your plugin instance)
```

क्रेडेंशियल **कभी भी** कच्चे रूप में पास नहीं किए जाते। `GatewayBridge`, `GatewayConfigRepository::findCredentialsBySlug()` को कॉल करता है, संग्रहीत JSON ब्लॉब को डिक्रिप्ट करता है, और प्लेन-टेक्स्ट की-वैल्यू मैप को आपके एडैप्टर मेथड्स में पास करता है।

## डायरेक्टरी संरचना {#directory-structure}

अपना गेटवे `modules/gateways/{your-slug}/` के अंदर रखें:

```text
modules/gateways/my-gateway/
+-- manifest.json           # Required. Plugin metadata and capabilities declaration.
+-- MyGateway.php           # Required. Entrypoint - implements PluginInterface + GatewayAdapterInterface.
+-- icon.svg                # Recommended. Gateway logo shown in admin panel.
+-- assets/                 # Optional. CSS/JS loaded on checkout page.
+-- migrations/             # Optional. SQL files executed on activation.
```

## manifest.json फ़ाइल {#the-manifest-json-file}

```json
{
  "name": "Stripe",
  "slug": "stripe",
  "version": "1.0.0",
  "description": "Stripe payment gateway - cards, wallets, international payments",
  "author": "OwnPay Core",
  "type": "gateway",
  "category": "global",
  "icon": "icon.svg",
  "color": "#635BFF",
  "entrypoint": "StripeGateway.php",
  "namespace": "OwnPay\\Modules\\Gateways\\Stripe",
  "capabilities": ["gateway"],
  "requires": {
    "core": ">=0.1.0",
    "php": ">=8.1"
  },
  "csp": {
    "script_src": ["https://*.stripe.com"],
    "style_src":  ["https://*.stripe.com"],
    "frame_src":  ["https://*.stripe.com"],
    "connect_src": ["https://api.stripe.com", "https://*.stripe.com"]
  },
  "permissions": ["gateway.process", "gateway.refund"]
}
```

## एंट्रीपॉइंट क्लास {#the-entrypoint-class}

गेटवे प्लगइन की एंट्रीपॉइंट क्लास को `OwnPay\Plugin\PluginInterface` और `OwnPay\Gateway\GatewayAdapterInterface` दोनों लागू करने होंगे:

```php
<?php
declare(strict_types=1);

namespace OwnPay\Modules\Gateways\MyGateway;

use OwnPay\Gateway\GatewayAdapterInterface;
use OwnPay\Gateway\GatewayDefaults;
use OwnPay\Plugin\PluginInterface;
use OwnPay\Plugin\Capability;
use OwnPay\Container;
use OwnPay\Event\EventManager;

final class MyGateway implements PluginInterface, GatewayAdapterInterface
{
    use GatewayDefaults;

    public static function metadata(): array
    {
        return [
            'name'        => 'My Gateway',
            'slug'        => 'my-gateway',
            'version'     => '1.0.0',
            'description' => 'My custom payment gateway.',
            'author'      => 'Your Name',
            'type'        => 'gateway',
        ];
    }

    public function capabilities(): array
    {
        return [Capability::GATEWAY];
    }

    public function register(EventManager $events, Container $container): void
    {
        // Register hooks here if needed
    }

    public function boot(Container $container): void {}

    public function deactivate(Container $container): void {}

    public function uninstall(Container $container): void {}

    public function fields(): array
    {
        return [
            [
                'name'     => 'api_key',
                'label'    => 'API Key',
                'type'     => 'password',
                'required' => true,
            ],
            [
                'name'     => 'mode',
                'label'    => 'Mode',
                'type'     => 'select',
                'options'  => ['sandbox' => 'Sandbox', 'live' => 'Live'],
                'required' => true,
            ],
        ];
    }

    public function slug(): string
    {
        return 'my-gateway';
    }

    public function initiate(array $params, array $credentials): array
    {
        // $params: amount, currency, trx_id, redirect_url, cancel_url
        // Return: redirect_url OR form_html OR session_id
    }

    public function verify(array $callbackData, array $credentials): array
    {
        // ALWAYS verify server-side with the gateway API
        // Return: ['success' => bool, 'gateway_trx_id' => string, 'amount' => string|null, 'status' => string]
    }

    public function verifyWebhook(string $rawBody, array $headers, array $credentials): bool
    {
        // Validate the inbound webhook signature
    }

    public function refund(string $gatewayTrxId, string $amount, array $credentials): array
    {
        // Return: ['success' => bool, 'refund_id' => string|null, 'error' => string|null]
    }

    public function supports(string $feature): bool
    {
        return match ($feature) {
            'refund', 'verification' => true,
            default                  => false,
        };
    }

    public function supportedCurrencies(): array
    {
        return []; // Empty = accepts any currency
    }
}
```

## मेथड कॉन्ट्रैक्ट {#method-contracts}

### `initiate(array $params, array $credentials): array` {#initiatearray-$params-array-$credentials-array}

पेमेंट सेशन शुरू करने के लिए कॉल किया जाता है। `$params` का यह गारंटीड स्वरूप होता है:

```php
[
    'amount'       => '150.00',      // BCMath-safe decimal string
    'currency'     => 'USD',
    'trx_id'       => 'OP-20240701-ABCD',
    'redirect_url' => 'https://pay.example.com/checkout/callback',
    'cancel_url'   => 'https://pay.example.com/checkout/cancel',
]
```

इनमें से एक लौटाएँ:

- `['redirect_url' => 'https://gateway.example.com/pay/SESSION_ID']`
- `['form_html' => '<form>...</form>']`
- `['session_id' => 'SESSION_ID']`

### `verify(array $callbackData, array $credentials): array` {#verifyarray-$callbackdata-array-$credentials-array}

**सुरक्षा नियम**: `$callbackData` से मिले पेमेंट स्टेटस पर कभी भरोसा न करें। हमेशा सर्वर-टू-सर्वर API कॉल करें।

### `verifyWebhook(string $rawBody, array $headers, array $credentials): bool` {#verifywebhookstring-$rawbody-array-$headers-array-$credentials-bool}

सभी HMAC तुलनाओं के लिए `hash_equals()` का उपयोग करें। पुराने टाइमस्टैम्प को अस्वीकार करके रीप्ले सुरक्षा शामिल करें।

### `refund(string $gatewayTrxId, string $amount, array $credentials): array` {#refundstring-$gatewaytrxid-string-$amount-array-$credentials-array}

`$gatewayTrxId` वह मान है जो आपके `verify()` ने लौटाया था। `$amount` एक BCMath-सुरक्षित दशमलव स्ट्रिंग है।

### `supports(string $feature): bool` {#supportsstring-$feature-bool}

| फ़ीचर | यह क्या सक्षम करता है |
| --- | --- |
| `refund` | पूर्ण ट्रांज़ैक्शन पर रिफ़ंड बटन दिखाया जाता है |
| `recurring` | सब्सक्रिप्शन/आवर्ती बिलिंग UI |
| `partial` | आंशिक रिफ़ंड राशि इनपुट |
| `verification` | सर्वर-साइड verify API उपलब्ध है |

## मल्टी-फ़ाइल प्लगइन {#multi-file-plugins}

`manifest.json` में एक `namespace` घोषित करें। `PluginLoader` एक PSR-4 ऑटोलोडर रजिस्टर करता है जो `{namespace}\{SubClass}` को `{plugin_dir}/{SubClass}.php` से मैप करता है।

## डेटाबेस माइग्रेशन {#database-migrations}

`.sql` फ़ाइलों के साथ एक `migrations/` डायरेक्टरी बनाएँ। प्लगइन टेबल के नाम `op_plugin_` उपसर्ग से शुरू होने चाहिए।

## कंटेंट सिक्योरिटी पॉलिसी {#content-security-policy}

यदि आपका गेटवे बाहरी JavaScript लोड करता है, तो `manifest.json` के अंदर `csp` में आवश्यक डोमेन घोषित करें।

## सुरक्षा आवश्यकताएँ {#security-requirements}

- कॉलबैक डेटा पर कभी भरोसा न करें - हमेशा सर्वर-साइड सत्यापित करें
- सभी HMAC तुलनाओं के लिए `hash_equals()` का उपयोग करें
- 5 मिनट से पुराने वेबहुक टाइमस्टैम्प को अस्वीकार करें
- यदि `webhook_secret` मौजूद नहीं है, तो `verifyWebhook()` को `false` लौटाना होगा
- कोई `eval()` या OS कमांड नहीं
- `op_*` टेबल तक कोई सीधी पहुँच नहीं

## इंस्टॉलेशन और सक्रियण {#installation-and-activation}

1. अपनी प्लगइन डायरेक्टरी को ZIP के रूप में पैकेज करें
2. Admin \> Gateways \> "Install Plugin" के माध्यम से अपलोड करें
3. गेटवे सूची के माध्यम से सक्रिय करें
4. गेटवे सेटिंग्स फ़ॉर्म के माध्यम से क्रेडेंशियल कॉन्फ़िगर करें

## चेकलिस्ट {#checklist}

- `manifest.json` सभी आवश्यक फ़ील्ड के साथ मौजूद है
- एंट्रीपॉइंट `PluginInterface` और `GatewayAdapterInterface` दोनों लागू करता है
- `slug()` बिल्कुल वही मान लौटाता है जो `manifest.json` में है
- `initiate()` एक मान्य रिस्पॉन्स स्वरूप लौटाता है
- `verify()` एक सर्वर-साइड API कॉल करता है
- `verifyWebhook()` `hash_equals()` का उपयोग करता है और टाइमस्टैम्प रीप्ले विंडो लागू करता है
- प्लगइन टेबल `op_plugin_` उपसर्ग का उपयोग करती हैं
- `eval()`, `exec()`, `shell_exec()` का कोई उपयोग नहीं
- CSP डोमेन `manifest.json` में घोषित हैं
