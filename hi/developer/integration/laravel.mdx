आधिकारिक OwnPay Laravel SDK आपके Laravel एप्लिकेशन में पेमेंट इंटीग्रेट करने के लिए एक साफ़, फ़्लूएंट इंटरफ़ेस प्रदान करता है। यह प्रमाणीकरण, पुनः प्रयास, वेबहुक सत्यापन और त्रुटि हैंडलिंग को शुरू से ही संभालता है।

## पूर्वापेक्षाएँ {#prerequisites}

- PHP 8.3 या उससे ऊपर
- Laravel 11.x, 12.x, या 13.x
- Admin \> Developer Hub से एक OwnPay API कुंजी

## इंस्टॉलेशन {#installation}

<Steps>
  <Step>
    **पैकेज इंस्टॉल करें**

    ```bash
    composer require ownpay/ownpay-laravel
    ```

    पैकेज अपने service provider और facade को स्वचालित रूप से रजिस्टर करता है।
  </Step>
  <Step>
    **कॉन्फ़िगरेशन पब्लिश करें**

    ```bash
    php artisan vendor:publish --tag=ownpay-config
    ```

    यह आपके एप्लिकेशन में `config/ownpay.php` बनाता है।
  </Step>
  <Step>
    **माइग्रेशन पब्लिश करें (वैकल्पिक)**

    यदि आप वेबहुक को डेटाबेस टेबल में लॉग करना चाहते हैं:

    ```bash
    php artisan vendor:publish --tag=ownpay-migrations
    php artisan migrate
    ```
  </Step>
  <Step>
    **एनवायरनमेंट वेरिएबल जोड़ें**

    इन्हें अपनी `.env` फ़ाइल में जोड़ें:

    ```env
    OWNPAY_API_KEY=op_live_abc123.def456
    OWNPAY_WEBHOOK_SECRET=your_webhook_secret_here
    OWNPAY_BASE_URL=https://pay.ownpay.org
    OWNPAY_TIMEOUT=30
    OWNPAY_RETRY_ATTEMPTS=3
    OWNPAY_RETRY_DELAY=100
    OWNPAY_VERIFY_SSL=true
    ```
  </Step>
</Steps>

## कॉन्फ़िगरेशन {#configuration}

`config/ownpay.php` में सभी विकल्प:

| विकल्प | डिफ़ॉल्ट | विवरण |
| --- | --- | --- |
| `api_key` | `null` | आपकी OwnPay API कुंजी (`op_` से शुरू होती है) |
| `webhook_secret` | `null` | सत्यापन के लिए वेबहुक साइनिंग सीक्रेट |
| `base_url` | `https://pay.ownpay.org` | आपके OwnPay इंस्टेंस का URL |
| `timeout` | `30` | सेकंड में अनुरोध टाइमआउट |
| `retry_attempts` | `3` | विफल अनुरोधों के लिए पुनः प्रयासों की संख्या |
| `retry_delay` | `100` | पुनः प्रयासों के बीच मिलीसेकंड में बेस देरी |
| `verify_ssl` | `true` | SSL सर्टिफ़िकेट सत्यापित करने हैं या नहीं |
| `log_channel` | `null` | SDK लॉगिंग के लिए लॉग चैनल |
| `cache_ttl` | `0` | सेकंड में कैश TTL (अक्षम करने के लिए 0) |

## पेमेंट बनाना {#creating-payments}

`OwnPay` facade का उपयोग करें या `OwnPayClient` को सीधे inject करें।

<Tabs>
  <Tab title="Facade">
    ```php
    use OwnPay\Laravel\Facades\OwnPay;
    
    $payment = OwnPay::createPayment([
        'amount'         => '1250.00',
        'currency'       => 'BDT',
        'description'    => 'Premium Subscription',
        'redirect_url'   => 'https://example.com/success',
        'cancel_url'     => 'https://example.com/cancel',
        'callback_url'   => 'https://example.com/webhook',
        'customer_name'  => 'John Doe',
        'customer_mail'  => 'john@example.com',
    ]);
    
    // Redirect the customer to checkout
    return redirect($payment->checkoutUrl);
    ```
  </Tab>
  <Tab title="Dependency Injection">
    ```php
    use OwnPay\Laravel\Client\OwnPayClient;
    
    class PaymentController extends Controller
    {
        public function __construct(
            private readonly OwnPayClient $ownpay,
        ) {}
    
        public function store(Request $request)
        {
            $payment = $this->ownpay->createPayment([
                'amount'       => $request->input('amount'),
                'currency'     => $request->input('currency'),
                'callback_url' => route('webhook.ownpay'),
            ]);
    
            return response()->json([
                'checkout_url' => $payment->checkoutUrl,
                'payment_id'   => $payment->paymentId,
            ]);
        }
    }
    ```
  </Tab>
</Tabs>

## पेमेंट फ़्लो {#payment-flow}

एक सामान्य चेकआउट फ़्लो इस तरह दिखता है:

```text
Customer clicks "Pay"
       |
       v
createPayment() -> get checkoutUrl
       |
       v
Redirect customer to OwnPay checkout
       |
       v
Customer completes or cancels payment
       |
       v
OwnPay sends webhook -> VerifyWebhookSignature middleware
       |
       v
Your listener updates order status
```

### पूरा उदाहरण {#full-example}

```php
use OwnPay\Laravel\Facades\OwnPay;
use OwnPay\Laravel\Exception\OwnPayExceptionInterface;

class CheckoutController extends Controller
{
    public function initiate(Request $request)
    {
        try {
            $payment = OwnPay::createPayment([
                'amount'        => $request->input('amount'),
                'currency'      => $request->input('currency'),
                'description'   => $request->input('description'),
                'redirect_url'  => route('payment.success'),
                'cancel_url'    => route('payment.cancel'),
                'callback_url'  => route('webhook.ownpay'),
                'customer_name' => $request->input('customer_name'),
                'customer_mail' => $request->input('customer_email'),
                'metadata'      => [
                    'order_id' => $request->input('order_id'),
                ],
            ]);

            // Store payment_id in your database
            // Redirect to checkout
            return redirect($payment->checkoutUrl);

        } catch (OwnPayExceptionInterface $e) {
            return back()->withErrors([
                'payment' => $e->getMessage(),
            ]);
        }
    }

    public function success(Request $request)
    {
        $paymentId = $request->query('payment_id');
        $payment = OwnPay::getPayment($paymentId);

        if ($payment->isSuccess()) {
            return view('payment.success', ['payment' => $payment]);
        }

        return view('payment.pending', ['payment' => $payment]);
    }
}
```

## वेबहुक हैंडलिंग {#webhook-handling}

### रूट सेटअप {#route-setup}

पैकेज `/webhooks/ownpay` पर एक वेबहुक रूट स्वचालित रूप से रजिस्टर करता है। आप इसे कस्टमाइज़ कर सकते हैं:

```php
use OwnPay\Laravel\Laravel\Middleware\VerifyWebhookSignature;

Route::post('/webhooks/ownpay', [WebhookController::class, 'handle'])
    ->middleware(VerifyWebhookSignature::class);
```

<Info>
  `VerifyWebhookSignature` middleware हर आने वाले वेबहुक पर HMAC-SHA256 सिग्नेचर को वैलिडेट करता है। किसी मैन्युअल सत्यापन की आवश्यकता नहीं है।
</Info>

### इवेंट सुनना {#listening-for-events}

अपने `EventServiceProvider` में एक इवेंट listener रजिस्टर करें:

```php
protected $listen = [
    \OwnPay\Laravel\Laravel\Events\WebhookReceived::class => [
        \App\Listeners\HandleOwnPayWebhook::class,
    ],
];
```

### उदाहरण listener {#example-listener}

```php
namespace App\Listeners;

use OwnPay\Laravel\Laravel\Events\WebhookReceived;

class HandleOwnPayWebhook
{
    public function handle(WebhookReceived $event): void
    {
        match ($event->event) {
            'payment.completed' => $this->handlePaymentCompleted($event),
            'payment.failed'    => $this->handlePaymentFailed($event),
            'refund.completed'  => $this->handleRefundCompleted($event),
            default             => null,
        };
    }

    private function handlePaymentCompleted(WebhookReceived $event): void
    {
        $transactionId = $event->getTransactionId();
        $amount = $event->getAmount();
        $currency = $event->getCurrency();

        // Update your database, send confirmation email, etc.
    }

    private function handlePaymentFailed(WebhookReceived $event): void
    {
        // Handle failed payment
    }

    private function handleRefundCompleted(WebhookReceived $event): void
    {
        // Handle completed refund
    }
}
```

## वैल्यू ऑब्जेक्ट {#value-objects}

SDK रॉ ऐरे के बजाय टाइप-सेफ़ वैल्यू ऑब्जेक्ट का उपयोग करता है।

### Money {#money}

```php
use OwnPay\Laravel\ValueObjects\Money;

$price = new Money('100.00', 'USD');
$price->toFloat();  // 100.0
$price->toCents();  // 10000
$price->format();   // "USD 100.00"

// Arithmetic
$a = new Money('100.00', 'USD');
$b = new Money('50.00', 'USD');
$sum = $a->add($b);       // Money('150.00', 'USD')
$diff = $a->subtract($b); // Money('50.00', 'USD')

// Comparison
$a->isGreaterThan($b); // true
$a->equals(new Money('100.00', 'USD')); // true
```

### स्टेटस enums {#status-enums}

```php
use OwnPay\Laravel\ValueObjects\PaymentStatus;
use OwnPay\Laravel\ValueObjects\TransactionStatus;

$status = PaymentStatus::from('completed');
$status->isSuccess();  // true
$status->isTerminal(); // true
$status->isActive();   // false
$status->label();      // "Completed"

$trxStatus = TransactionStatus::from('completed');
$trxStatus->isRefundable(); // true
```

## त्रुटि हैंडलिंग {#error-handling}

SDK एक संरचित exception पदानुक्रम प्रदान करता है:

```php
use OwnPay\Laravel\Exception\OwnPayExceptionInterface;
use OwnPay\Laravel\Exception\AuthenticationException;
use OwnPay\Laravel\Exception\InvalidRequestException;
use OwnPay\Laravel\Exception\NotFoundException;
use OwnPay\Laravel\Exception\RateLimitException;
use OwnPay\Laravel\Exception\ConnectionException;

try {
    $payment = OwnPay::createPayment([...]);
} catch (AuthenticationException $e) {
    Log::error('OwnPay auth error: ' . $e->getMessage());
} catch (InvalidRequestException $e) {
    $errors = $e->getErrorDetails(); // Array of {code, message, field}
} catch (NotFoundException $e) {
    // Resource not found
} catch (RateLimitException $e) {
    $retryAfter = $e->getRetryAfter();
} catch (ConnectionException $e) {
    // Network error
} catch (OwnPayExceptionInterface $e) {
    // Catch all OwnPay exceptions
}
```

<Accordion title="Exception संदर्भ">
  | Exception | HTTP कोड | कब थ्रो होता है |
  | --- | --- | --- |
  | `AuthenticationException` | 401 | अमान्य या अनुपस्थित API कुंजी |
  | `InvalidRequestException` | 422 | अनुरोध बॉडी में वैलिडेशन त्रुटियाँ |
  | `NotFoundException` | 404 | रिसोर्स मौजूद नहीं है |
  | `RateLimitException` | 429 | बहुत अधिक अनुरोध |
  | `ConnectionException` | - | नेटवर्क या टाइमआउट त्रुटियाँ |
</Accordion>

### टेस्ट में वेबहुक सत्यापित करना {#verifying-webhooks-in-tests}

```php

$result = $verifier->verify($payload, $signature);
$this->assertSame('payment.completed', $result['event']);
```

## सुरक्षा सर्वोत्तम प्रथाएँ {#security-best-practices}

<Warning>
  API कुंजियों को कभी भी वर्ज़न कंट्रोल में कमिट न करें। हमेशा एनवायरनमेंट वेरिएबल का उपयोग करें।
</Warning>

1. API कुंजियों को सीधे `config/ownpay.php` में नहीं, बल्कि `.env` में संग्रहीत करें
2. सभी API संचार के लिए HTTPS का उपयोग करें
3. SDK `VerifyWebhookSignature` middleware के माध्यम से वेबहुक सिग्नेचर स्वचालित रूप से सत्यापित करता है
4. API कुंजियाँ `#[\SensitiveParameter]` attribute के साथ संग्रहीत होती हैं - वे कभी लॉग नहीं होतीं और न ही त्रुटि संदेशों में दिखाई देती हैं
5. महत्वपूर्ण पेमेंट ऑपरेशन के लिए idempotency लागू करें
6. ऑडिट ट्रेल के लिए सभी पेमेंट इवेंट लॉग करें
