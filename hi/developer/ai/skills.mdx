OwnPay ऐसी **skills** प्रदान करता है जो AI एजेंट को OwnPay प्लेटफ़ॉर्म के साथ काम करना सिखाती हैं। Skill एक संरचित नॉलेज फ़ाइल है जो AI टूल्स को OwnPay के आर्किटेक्चर, API, परिपाटियों और सर्वोत्तम प्रथाओं के बारे में संदर्भ देती है।

<Info>
  OwnPay के साथ AI टूल्स का उपयोग करते समय बेहतर परिणाम पाने के लिए OwnPay skill इंस्टॉल करें। यह skill एजेंट को पेमेंट गेटवे आर्किटेक्चर, मल्टी-ब्रांड सिस्टम, प्लगइन डेवलपमेंट और API पैटर्न की जानकारी देती है।
</Info>

## Skills क्या हैं? {#what-are-skills}

Skills ऐसी फ़ाइलें हैं जो AI एजेंट को किसी प्रोडक्ट का प्रभावी ढंग से उपयोग करने का तरीका बताती हैं। जब आप OwnPay skill इंस्टॉल करते हैं, तो Claude, Cursor और VS Code जैसे AI टूल्स को मिलता है:

- **आर्किटेक्चर ज्ञान** - मल्टी-ब्रांड, गेटवे और लेजर सिस्टम की समझ
- **API पैटर्न** - REST API, वेबहुक और SDK का उपयोग कैसे करें
- **प्लगइन डेवलपमेंट** - गेटवे, ऐडऑन और थीम प्लगइन कैसे बनाएँ
- **सर्वोत्तम प्रथाएँ** - सुरक्षा, त्रुटि हैंडलिंग और टेस्टिंग पैटर्न
- **कोड उदाहरण** - PHP, Node.js और cURL में काम करने वाले उदाहरण

## Skill इंस्टॉल करें {#install-the-skill}

### त्वरित इंस्टॉलेशन {#quick-install}

अपने टर्मिनल में यह कमांड चलाएँ:

```bash
npx skills add {{docs-url}}
```

यह आपके सिस्टम पर सभी संगत AI टूल्स के लिए OwnPay skill डाउनलोड और इंस्टॉल करता है।

## Skill क्या सिखाती है {#what-the-skill-teaches}

OwnPay skill इन क्षेत्रों को कवर करती है:

### मुख्य आर्किटेक्चर {#core-architecture}

- **मल्टी-ब्रांड सिस्टम** - ब्रांड ग्राहकों, गेटवे और सेटिंग्स को कैसे अलग रखते हैं
- **पेमेंट फ़्लो** - चेकआउट बनने से लेकर सेटलमेंट तक
- **Double-entry लेजर** - वित्तीय अखंडता और बहीखाता
- **प्लगइन सिस्टम** - गेटवे, ऐडऑन और थीम प्लगइन आर्किटेक्चर

### API इंटीग्रेशन {#api-integration}

- **REST API** - प्रमाणीकरण, एंडपॉइंट, त्रुटि हैंडलिंग
- **वेबहुक** - इवेंट प्रकार, सिग्नेचर सत्यापन, पुनः प्रयास लॉजिक
- **SDKs** - PHP और Node.js SDK उपयोग पैटर्न
- **Payment intents** - पेमेंट बनाना और पुष्टि करना

### डेवलपमेंट पैटर्न {#development-patterns}

- **गेटवे प्लगइन** - कस्टम पेमेंट गेटवे इंटीग्रेशन बनाना
- **ऐडऑन प्लगइन** - नई सुविधाओं के साथ OwnPay का विस्तार करना
- **थीम प्लगइन** - चेकआउट अनुभव को कस्टमाइज़ करना
- **हुक और फ़िल्टर** - इवेंट-आधारित कस्टमाइज़ेशन

### ऑपरेशन {#operations}

- **इंस्टॉलेशन** - शेयर्ड होस्टिंग, VPS और Docker डिप्लॉयमेंट
- **कॉन्फ़िगरेशन** - एनवायरनमेंट वेरिएबल, cron जॉब, कैशिंग
- **सुरक्षा** - PCI अनुपालन, API कुंजी प्रबंधन, 2FA
- **समस्या-निवारण** - सामान्य समस्याएँ और समाधान

## MCP के साथ skill का उपयोग {#using-the-skill-with-mcp}

सर्वोत्तम अनुभव के लिए, skill को [OwnPay MCP सर्वर](/hi/developer/ai-mcp) के साथ मिलाएँ:

1. **Skill इंस्टॉल करें** - AI एजेंट को पृष्ठभूमि ज्ञान देती है
2. **MCP सर्वर कनेक्ट करें** - AI एजेंट को डॉक्स तक रीयल-टाइम एक्सेस देता है

साथ मिलकर, AI एजेंट OwnPay के आर्किटेक्चर को समझता है और नवीनतम डॉक्यूमेंटेशन भी खोज सकता है।

<Tip>
  Skill AI को सिखाती है कि OwnPay _कैसे_ काम करता है। MCP सर्वर उसे यह जानने की सुविधा देता है कि डॉक्स _क्या_ कहते हैं। सबसे सटीक परिणामों के लिए दोनों का उपयोग करें।
</Tip>

## इंस्टॉल करने के बाद उदाहरण प्रॉम्प्ट {#example-prompts-after-installing}

Skill इंस्टॉल होने के बाद, ये प्रॉम्प्ट आज़माएँ:

### डेवलपमेंट {#development}

- _"एक नए पेमेंट प्रोवाइडर के लिए गेटवे प्लगइन बनाएँ"_
- _"payment.completed इवेंट के लिए वेबहुक हैंडलर बनाएँ"_
- _"मुझे दिखाएँ कि PHP SDK का उपयोग करके payment intent कैसे बनाएँ"_

### आर्किटेक्चर {#architecture}

- _"समझाएँ कि मल्टी-ब्रांड डेटा आइसोलेशन कैसे काम करता है"_
- _"Double-entry लेजर ट्रांज़ैक्शन को कैसे ट्रैक करता है?"_
- _"पेमेंट फ़्लो को कस्टमाइज़ करने के लिए कौन-से हुक उपलब्ध हैं?"_

### ऑपरेशन {#operations}

- _"मैं cPanel शेयर्ड होस्ट पर OwnPay कैसे सेट अप करूँ?"_
- _"बेहतर परफ़ॉर्मेंस के लिए Redis कैशिंग कॉन्फ़िगर करें"_
- _"वेबहुक पुनः प्रयासों के लिए cron जॉब सेट अप करें"_

## Skill फ़ाइल का स्थान {#skill-file-location}

Skill फ़ाइल यहाँ होस्ट की गई है:

```text
{{skills-url}}
```

Mintlify आपके डॉक्यूमेंटेशन की संरचना और कंटेंट से यह फ़ाइल स्वचालित रूप से जनरेट करता है। इसमें शामिल हैं:

- प्रोजेक्ट अवलोकन और विवरण
- सुविधाओं की सूची और क्षमताएँ
- API एंडपॉइंट सारांश
- डॉक्यूमेंटेशन से कोड उदाहरण
- आर्किटेक्चर पैटर्न और परिपाटियाँ

## Skill को अपडेट करना {#updating-the-skill}

जब आप नया डॉक्यूमेंटेशन डिप्लॉय करते हैं, तो skill फ़ाइल स्वचालित रूप से अपडेट हो जाती है। किसी मैन्युअल अपडेट की आवश्यकता नहीं - बस अपने डॉक्स के बदलाव GitHub पर पुश करें और skill फिर से जनरेट हो जाती है।
