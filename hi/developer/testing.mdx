आप वास्तविक ट्रांज़ैक्शन प्रोसेस किए बिना अपने पूरे पेमेंट फ़्लो को टेस्ट कर सकते हैं। OwnPay टेस्ट कार्ड नंबर, सैंडबॉक्स गेटवे और वेबहुक सिमुलेशन का समर्थन करता है।

## गेटवे सैंडबॉक्स कॉन्फ़िगरेशन {#gateway-sandbox-configuration}

प्रत्येक गेटवे में एक सैंडबॉक्स या टेस्ट मोड होता है जिसे आप एडमिन पैनल से सक्रिय करते हैं। नीचे दी गई तालिका दिखाती है कि टेस्ट क्रेडेंशियल कहाँ मिलेंगे:

| गेटवे | सैंडबॉक्स सक्रियण | टेस्ट क्रेडेंशियल कहाँ से प्राप्त करें |
| --- | --- | --- |
| Stripe | गेटवे सेटिंग्स में **Test Mode** टॉगल करें | [Stripe Dashboard → Developers → Test mode](https://dashboard.stripe.com/test/apikeys) |
| PayPal | सैंडबॉक्स एंडपॉइंट URL का उपयोग करें | [PayPal Developer → Sandbox → Apps](https://developer.paypal.com/developer/applications/sandbox) |
| bKash | सैंडबॉक्स URL और टोकन का उपयोग करें | [https://tokenized.sandbox.bka.sh/v1.2.0-beta](https://tokenized.sandbox.bka.sh/v1.2.0-beta) |
| Nagad | सैंडबॉक्स URL और मर्चेंट ID का उपयोग करें | सैंडबॉक्स क्रेडेंशियल के लिए Nagad से संपर्क करें |
| SSLCommerz | गेटवे सेटिंग्स में **Sandbox** टॉगल करें | [SSLCommerz Sandbox](https://sandbox.sslcommerz.com/) |

## API के माध्यम से टेस्ट पेमेंट बनाना {#creating-a-test-payment-via-api}

```bash
curl -X POST https://your-domain.com/api/v1/payments \
  -H "Authorization: Bearer $OWNPAY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": "10.00",
    "currency": "USD",
    "customer_email": "test@example.com",
    "description": "Test payment",
    "metadata": { "test": true }
  }'
```

टेस्ट कार्ड के साथ चेकआउट फ़्लो पूरा करने के लिए लौटाए गए `checkout_url` का उपयोग करें।

## वेबहुक सिम्युलेट करना {#simulating-webhooks}

### Developer Hub से {#from-the-developer-hub}

1. **Developers → Webhooks** पर जाएँ
2. अपने एंडपॉइंट के आगे **Send Test Event** पर क्लिक करें
3. एक इवेंट प्रकार चुनें (उदाहरण के लिए `payment.completed`)
4. OwnPay एक मान्य सिग्नेचर के साथ एक यथार्थवादी पेलोड भेजता है

### cURL के माध्यम से {#via-curl}

आप मैन्युअल रूप से भी एक टेस्ट इवेंट ट्रिगर कर सकते हैं:

```bash
curl -X POST https://your-domain.com/api/v1/webhooks/test \
  -H "Authorization: Bearer $OWNPAY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "endpoint_id": "we_abc123",
    "event": "payment.completed"
  }'
```

## रिफ़ंड टेस्ट करना {#testing-refunds}

पहले एक पूर्ण टेस्ट पेमेंट बनाएँ, फिर रिफ़ंड जारी करें:

```bash
curl -X POST https://your-domain.com/api/v1/payments/pay_abc123/refunds \
  -H "Authorization: Bearer $OWNPAY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": "10.00",
    "reason": "Customer request"
  }'
```

<Note>
  टेस्ट मोड में रिफ़ंड तुरंत होते हैं और वास्तविक पैसा स्थानांतरित नहीं करते।
</Note>

लॉग निरीक्षण और रिक्वेस्ट ट्रेसिंग सहित गहन डीबगिंग के लिए, [डीबग मोड](/hi/resources/debug-mode) देखें।
