**telegram-bot** addon जब भी कोई प्रमुख पेमेंट इवेंट होता है, Telegram चैट में तुरंत पुश नोटिफ़िकेशन भेजता है। यह ईमेल से तेज़ है और उन ऑपरेटर्स के लिए आदर्श है जो अपने फ़ोन पर रीयल-टाइम अलर्ट चाहते हैं।

<Note>
  इस addon को कॉन्फ़िगर करने से पहले आपको एक Telegram Bot API टोकन और एक लक्ष्य chat ID की आवश्यकता है। दोनों मुफ़्त में प्राप्त किए जा सकते हैं।
</Note>

## पूर्वापेक्षाएँ {#prerequisites}

1. Telegram खोलें और **@BotFather** को संदेश भेजें
2. `/newbot` भेजें और अपना बॉट बनाने के लिए निर्देशों का पालन करें
3. BotFather द्वारा दिया गया **Bot API Token** कॉपी करें
4. अपने बॉट को किसी ग्रुप या चैनल में जोड़ें, या उसके साथ सीधी चैट शुरू करें
5. उस चैट में एक संदेश भेजें, फिर अपना **chat ID** खोजने के लिए `https://api.telegram.org/bot<TOKEN>/getUpdates` पर जाएँ

## इंस्टॉल और कॉन्फ़िगर करें {#install-and-configure}

<Steps>
  <Step>
    **telegram-bot** addon इंस्टॉल करें। इंस्टॉलेशन निर्देशों के लिए [Addons](/hi/system/addons) देखें।
  </Step>
  <Step>
    **System \> Addons** पर जाएँ, **Telegram Bot** खोजें, और **Settings** पर क्लिक करें।
  </Step>
  <Step>
    दिए गए फ़ील्ड में अपना **Bot API Token** और **Chat ID** दर्ज करें।
  </Step>
  <Step>
    **Active** को टॉगल करें और चुनें कि कौन से ब्रांड Telegram नोटिफ़िकेशन भेजें।
  </Step>
  <Step>
    **Save** पर क्लिक करें। कनेक्शन की पुष्टि के लिए एक टेस्ट संदेश भेजा जाता है।
  </Step>
</Steps>

## समर्थित इवेंट्स {#supported-events}

Telegram बॉट इन इवेंट्स के लिए नोटिफ़िकेशन भेजता है:

- `payment.completed` - पेमेंट सफलतापूर्वक प्राप्त हुआ
- `payment.failed` - पेमेंट प्रयास विफल रहा
- `refund.issued` - रिफ़ंड प्रोसेस किया गया

प्रत्येक नोटिफ़िकेशन में ट्रांज़ैक्शन राशि, मुद्रा, गेटवे का नाम, ग्राहक ईमेल (आंशिक), और एडमिन पैनल में ट्रांज़ैक्शन का लिंक शामिल होता है।

<Warning>
  ट्रांज़ैक्शन राशियाँ और आंशिक ग्राहक पहचानकर्ता Telegram संदेशों में दिखाई देते हैं। बॉट को केवल निजी चैट या भरोसेमंद टीम ग्रुप में ही जोड़ें। सार्वजनिक चैनलों से बचें।
</Warning>

## समस्या निवारण {#troubleshooting}

| लक्षण | संभावित कारण | समाधान |
| --- | --- | --- |
| बॉट को अपडेट नहीं मिलते | Privacy mode ग्रुप संदेशों को ब्लॉक कर रहा है | @BotFather को `/setprivacy` भेजें और अपने बॉट के लिए **Disable** चुनें |
| `401 Unauthorized` त्रुटि | अमान्य या रद्द किया गया बॉट टोकन | @BotFather से टोकन फिर से जनरेट करें और addon सेटिंग्स अपडेट करें |
| कोई संदेश डिलीवर नहीं हुआ | गलत chat ID | `getUpdates` का उपयोग करके अपना chat ID फिर से प्राप्त करें और सत्यापित करें कि बॉट लक्ष्य चैट का सदस्य है |
| संदेश आते हैं लेकिन विवरण नहीं होते | ब्रांड के लिए addon सक्रिय नहीं है | addon सेटिंग्स में जाएँ और सुनिश्चित करें कि सही ब्रांड सक्रिय पर टॉगल किया गया है |
