## [0.2.0] - 2026-07-07 {#0-2-0-2026-07-07}

### 新增 {#added}

- 自定义主题现在可以注册自己的渲染引擎（除内置模板引擎之外），并且新增了品牌级的“外观”页面，让每个品牌可以独立选择自己的主题。
- 主题在激活前会先扫描危险代码模式，不安全的主题会被阻止并显示明确的警告，而不是被静默激活。
- 插件可以声明其所依赖的其他插件；激活插件时会先检查其依赖是否已安装并处于激活状态，而不是在之后以令人困惑的方式失败。
- 结账页面新增了两个自定义扩展点：网关可以在网关列表中自己的名称旁添加自定义标记，商户可以向结账页面注入额外的表单字段，这些字段会随付款一起提交。
- 管理面板新增了可插拔的渲染引擎系统以及样式表/脚本“入队”（enqueue）系统，主题和管理页面可以干净地注册自己的资源，而无需将标签硬编码到模板中。
- 插件声明的必填设置字段现在会在保存时于服务器端进行验证，而不仅仅是在浏览器中验证，从而堵住了脚本化请求可以完全绕过“必填”标记的漏洞。
- API 密钥现在可以被临时锁定（暂停）而无需完全撤销，管理员可以在一个列表中查看每个密钥的状态——激活、锁定或已撤销。
- 开发者中心页面已重新组织：端点参考和身份验证已合并到“API 密钥”选项卡中，与 Webhook 相关的设置被单独拆分出来以便更清晰。
- “域名”页面已重新设计，采用卡片式布局、每个域名的选项卡式管理面板，以及用于添加新域名的 3 步引导向导，取代了旧的平面表格和静态说明。
- 手动（线下）支付方式新增了专用的付款/账户号码字段，面向客户的手动支付弹窗也已重新设计，包含网关徽标、二维码和一键复制金额按钮。
- 每次数据库结构变更现在都附带相应的升级文件，因此现有安装在更新时会自动获取新的数据库列，而无需重新安装。
- 系统更新成功后，旧的日志文件现在会作为例行维护的一部分被自动清理。

### 变更 {#changed}

- 安装向导已重建为专用的全屏体验，具有更简洁的步骤跟踪器、可恢复的进度，以及跳过可选步骤的选项。
- 完成或关闭安装向导后，管理员现在总是会进入“所有品牌”视图，而不是单个品牌。
- 登录后，超级管理员（以及任何被授予“所有品牌”访问权限的员工）现在会正确进入全局“所有品牌”视图，而不是总被带到单个品牌的仪表板。
- 结账页面上的网关选择现在在所有支付方式选项卡中表现一致，列表中的网关徽标也更大、更易辨认。

### 修复 {#fixed}

- 手动网关结账弹窗不再显示空白的 $0.00 金额，并且现在会在页脚正确显示品牌名称。
- 四个支付网关适配器不再将无法访问的 Webhook 确认视为已完成的付款（“失败放行”）；它们现在会正确等待真正的确认。
- 结账不再允许对同一笔付款的两次快速提交都通过，并且通过浏览器后退按钮返回结账页面时不再导致页面处于损坏状态。
- 修复了通过支付意图处理付款时，网关解析出的货币、金额和费用可能错误的问题。
- 发票生成的 PDF 中不再显示占位文本，发票没有任何明细项时不再崩溃，并且会正确记录付款日期。
- 支付链接现在可以从“所有品牌”视图中编辑，链接名称重复时不再返回服务器错误，并且现在会正确验证输入。
- 修复了安装向导中的复制到剪贴板按钮（OTP 和账户号码）在某些浏览器环境下静默失败的问题。
- 主题首次激活时不再错误地报告“激活失败”，而实际上激活已成功。
- 移除域名、切换域名管理面板以及域名向导的 UI 状态中存在的问题均已修复。
- 修复了若干代表真实逻辑错误的 PHPStan 静态分析错误，包括应用程序日志记录器设置中的参数顺序错误以及无法到达的验证代码。
- 修复了一条过于宽泛的版本控制忽略规则，该规则意外地隐藏了一个真实的源代码文件夹。

### 安全 {#security}

- 支付网关凭据（API 密钥、密钥、密码）现在以加密方式静态存储，而不是以明文存储，并且不再回显到设置表单中。
- 修复了 Webhook 管道中的一个漏洞：此前网关身份未经完全验证，且存在服务器端请求伪造（SSRF）攻击途径。
- 发票 PDF 下载现在会对输出文件名进行清理，以防止路径遍历。
- 品牌“外观”（主题）页面现在正确要求插件查看/管理权限，而不再对任何拥有管理员访问权限的人开放。

> 网关平台。由单一所有者运营整个系统；多个
> 品牌（商店）在隔离的自定义域名下运行——每个品牌都有自己的网关、账本、
> 客户和视觉标识。
