## 我们的承诺 {#our-pledge}

我们致力于为每一位参与 OwnPay 社区的人提供一个友好、包容且无骚扰的环境，无论其背景、身份或经验水平如何。我们重视每个人的贡献，并相信多元化的社区能够打造出更好的软件。

---

## 我们的标准 {#our-standards}

### 期望的行为 {#expected-behavior}

- 在所有互动中使用友好且包容的语言
- 坦然接受建设性的批评，并以深思熟虑的方式提出批评
- 专注于对整个社区最有利的事情
- 对其他社区成员表现出同理心
- 尊重不同的观点、经验水平和沟通方式
- 帮助新人入门并找到方向

### 不可接受的行为 {#unacceptable-behavior}

- 骚扰、侮辱或贬损性言论
- 恶意挑衅、故意引发冲突或发布与主题无关的内容
- 任何形式的公开或私下骚扰
- 未经明确同意公开他人的私人信息
- 鼓吹或鼓励任何形式的歧视
- 在专业环境中被视为不当的其他行为

---

## 适用范围 {#scope}

本行为准则适用于所有 OwnPay 社区空间，包括但不限于：

- GitHub 仓库（issue、pull request、讨论、评审）
- Discord 服务器及其他聊天平台
- 官方文档和网站
- 社区活动、聚会和会议
- 与维护者的电子邮件往来

---

## 职责 {#responsibilities}

### 管理者 {#moderators}

项目维护者负责阐明并执行本行为准则。他们将：

- 及时回应任何被举报的不可接受行为
- 采取适当的纠正措施，从警告到临时或永久封禁不等
- 及时将处理决定告知举报人
- 尽可能对举报人的身份保密

### 执行 {#enforcement}

不可接受行为的情况可通过联系 {{supportEmail}} 进行举报。所有投诉都将得到公正的审查和调查。
