短信中心为您提供 OwnPay 实例中所有短信活动的集中视图。您可以查看由[配套应用](/zh/mobile/companion-app)转发的**付款确认**短信，检查外发通知短信（如已配置），并监控队列健康状况。

<Note>
  配套应用仅转发**收款回执短信**（例如 bKash/Nagad/Rocket 的确认短信）。OTP 验证码、个人短信以及所有其他非付款短信都会在设备端被过滤，绝不会到达您的 OwnPay 服务器。短信中心只显示通过此过滤的消息。
</Note>

## 查看短信日志 {#view-sms-logs}

前往 **Notifications \> SMS Center**。主表格显示系统处理过的每一条短信。

| 列 | 描述 |
| --- | --- |
| **Phone number** | 发送方或接收方号码 |
| **Direction** | 接收（来自配套应用）或外发 |
| **Transaction** | 关联的交易 ID（如已匹配） |
| **Gateway** | 触发该短信的支付网关（如适用） |
| **Status** | 已处理、已排队、失败或已忽略 |
| **Timestamp** | 短信接收或发送的时间 |

使用搜索栏可按**电话号码**或**交易 ID** 筛选日志。日期范围选择器可让您将结果缩小到特定时间段。

## 接收短信 {#incoming-sms}

接收的短信通过 [Mobile API](/zh/api/overview) 从 Android 配套应用到达。当设备收到短信时，配套应用的设备端隐私过滤器会检查其是否像付款确认短信。只有收款回执短信会被转发；其他所有短信（OTP、个人、推广）都会被静默丢弃。随后，系统会尝试将转发的消息与启用的[短信验证模板](/zh/mobile/sms-templates)进行匹配，并自动完成关联的交易。

<Info>
  未匹配任何模板的收款短信仍会被记录以供审计。您可以查看未匹配的消息，以找出需要更新的模板。
</Info>

## 外发短信 {#outbound-sms}

当您的网关或插件触发面向客户的短信时，就会发送外发短信。短信中心会显示每条外发消息的投递队列状态：

<Columns>
  <Column>
    **Queued** - 等待发送

    **Sent** - 已移交给短信服务商
  </Column>
  <Column>
    **Delivered** - 服务商已确认送达

    **Failed** - 投递失败；请查看错误列
  </Column>
</Columns>

## 短信模板测试 {#sms-template-testing}

您可以直接从短信中心发送测试短信，以验证模板和网关路由是否正常工作。输入电话号码，选择模板，然后点击 **Send Test**。该消息会以 `test` 标签显示在日志中。

## 队列状态 {#queue-status}

页面顶部的 **Queue Status** 卡片显示实时计数：

- 队列中等待的消息
- 过去一小时内发送的消息
- 过去一小时内失败的消息

如果失败数量意外上升，请检查您的短信服务商凭据和网关配置。
