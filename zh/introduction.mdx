欢迎使用 **OwnPay** —— 一个开源的自托管支付编排平台，让您完全掌控业务的收款方式。您无需将每笔交易都路由到第三方处理商，而是可以在自己信任的基础设施上运行自己的网关服务器。

OwnPay 通过统一的 API 连接 123+ 个支付网络（Stripe、PayPal、bKash、Nagad、Razorpay、SSLCommerz 等），并允许您从一个仪表板管理多个隔离的商户品牌。每笔支付都记录在内置的复式记账账本中，确保审计级别的财务追踪。

## 核心功能

  <Card title="100+ 支付网关" icon="wallet">
    通过单一集成点接受信用卡、移动钱包、银行转账和本地支付方式，覆盖 50+ 个国家。
  </Card>
  <Card title="多租户品牌" icon="store">
    从单个 OwnPay 实例运行隔离的商户租户 —— 每个品牌拥有自己的网关、域名、品牌标识、员工、API 密钥和账本。
  </Card>
  <Card title="复式记账账本" icon="book-open">

  </Card>
  <Card title="白标域名" icon="globe">
    在自定义域名（如 `pay.yourbrand.com`）上提供品牌化的结账页面，支持自动 SSL 配置和 DNS 验证。
  </Card>
</CardGroup>

## OwnPay 的独特之处

- **自托管，完全数据主权** —— 您的服务器、您的数据库、您的规则。没有第三方能看到您的客户数据或交易历史。
- **内置 123+ 网关** —— 国际处理器（Stripe、PayPal）与区域领导者（bKash、Nagad、GCash、Razorpay、SSLCommerz）并存，每个版本都有新增。
- **OwnPay 零交易手续费** —— 采用 AGPL-3.0 许可证，无每笔交易收费。您只需支付网关自身的处理费用。
- **AGPL-3.0 许可，永久免费** —— 无许可层级，无功能限制，无电话回传遥测。完整源代码在 [GitHub]({{github}}) 上。
- **插件可扩展架构** —— 无需修改核心代码即可添加网关、主题、插件和集成。拥有 60+ 个钩子和完整的 WordPress 风格生命周期。
- **复式记账账本** —— 会计级别的财务追踪，具有借贷平衡验证、品牌隔离和内置对账功能。
