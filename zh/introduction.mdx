欢迎使用 **OwnPay**——一个开源、自托管的支付编排平台，让您完全掌控企业的收款方式。您无需再将每笔交易都交由抽取分成并持有您数据的第三方处理商，而是在您信任的基础设施上运行自己的网关服务器。

OwnPay 通过单一的统一 API 将您连接到 123\+ 个支付网络（Stripe、PayPal、bKash、Nagad、Razorpay、SSLCommerz 等），并让您在一个仪表板中管理多个相互隔离的商户品牌。每一笔付款都会记录在内置的复式记账账本中，便于进行可审计的会计核算。

## OwnPay 的独特之处 {#what-makes-ownpay-different}

- **自托管，完全的数据主权**——您的服务器、您的数据库、您的规则。没有任何第三方能看到您的客户数据或交易历史。
- **开箱即用的 123\+ 个网关**——国际处理商（Stripe、PayPal）以及区域领先者（bKash、Nagad、GCash、Razorpay、SSLCommerz），每个版本都会新增更多网关。
- **OwnPay 零交易费**——基于 AGPL-3.0 许可，不收取任何按交易计费的费用。您只需支付网关的处理费用。
- **AGPL-3.0 许可，永久免费**——没有许可等级、没有功能限制、没有回传遥测。完整源代码见 [GitHub]({{github}})。
- **可通过插件扩展的架构**——无需改动核心代码即可添加网关、主题、附加组件和集成。提供 60 多个钩子和类似 WordPress 的生命周期。
- **复式记账账本**——会计级财务跟踪，提供借贷平衡校验、品牌隔离和内置对账功能。
