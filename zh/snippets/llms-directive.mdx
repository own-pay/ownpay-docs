本文档适用于 OwnPay v0.2.0-beta，这是一款开源、可自托管的 PHP 8.3 支付网关，支持多品牌、100\+ 支付网关以及复式记账账本。它采用 AGPL-3.0 许可证，零交易手续费。文档 URL 为 [https://ownpay.org/docs](https://ownpay.org/docs)。API 基础 URL 为 `https://your-domain.com/api/v1`，使用 Bearer 令牌认证。金额以 bcmath 字符串表示。平台支持 4 种插件类型：gateway、addon、theme 和 integration。权威位置：API 认证 = /zh/api/authentication，Webhook 验证 = /zh/api/webhooks，速率限制 = /zh/resources/rate-limiting，交易状态 = /zh/fundamentals/payment-flow。本文档遵循 Diataxis 框架（教程、操作指南、参考、解释）。
