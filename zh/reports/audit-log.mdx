审计日志记录员工在管理面板中执行的每一项重要操作。它是您进行合规报告、安全调查和问责追踪的主要工具。

## 记录的内容 {#what-is-logged}

OwnPay 记录以下操作类别：

- **身份验证** - 登录、退出、失败的尝试、2FA 事件
- **财务** - 付款创建、手动退款、账本调整
- **配置** - 设置更改、网关修改、品牌更新
- **数据** - 客户创建、发票生成、导出操作
- **系统** - 插件安装、附加组件激活、系统更新

## 日志条目字段 {#log-entry-fields}

每条审计日志条目包含：

| 字段 | 描述 |
| --- | --- |
| **Timestamp** | 精确的日期和时间（使用您配置的时区） |
| **User** | 执行该操作的员工 |
| **Action** | 操作类型（例如 `payment.refund.create`） |
| **Entity** | 受影响的资源（例如交易 ID、品牌 ID） |
| **Changes** | 更新操作前后值的 JSON 差异 |
| **IP Address** | 请求者的 IP 地址 |

## 搜索和筛选 {#search-and-filter}

使用搜索栏按**用户名**、**操作类型**或**实体 ID** 查找条目。结合日期范围选择器和操作类别下拉菜单来缩小结果范围。

<Info>
  审计日志查询在 changes 字段上使用全文索引，因此即使有数百万条记录，在变更差异中搜索特定值也很快。
</Info>

## 导出 {#export}

点击 **Export CSV** 下载当前筛选出的日志条目。导出内容包含所有字段，适用于外部合规审查或归档。

<Warning>
  导出的 CSV 文件包含敏感数据，包括 IP 地址和变更差异。请安全存储导出文件，切勿将其提交到版本控制系统。
</Warning>

## 保留策略 {#retention-policy}

默认情况下，审计日志会无限期保留。如果您的合规要求规定了特定的保留期限，您可以在 **Settings \> Advanced \> Audit Log Retention (days)** 中配置自动清理。设置为 `0` 可禁用自动清理。
