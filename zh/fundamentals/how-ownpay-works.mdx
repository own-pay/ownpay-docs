OwnPay 位于您的业务和 123\+ 个支付提供商之间。当客户点击"支付"时，OwnPay 将支付路由到正确的网关，将结果记录在复式记账账本中，并向您的应用发送 Webhook —— 所有这些都在您控制的基础设施上完成。

## OwnPay 的独特之处

- **自托管，完全数据主权** —— 您的服务器、您的数据库、您的规则。客户个人身份信息使用 AES-256-GCM 静态加密。没有第三方能看到您的数据。
- **内置 123\+ 网关** —— 国际处理器（Stripe、PayPal）与区域领导者（bKash、Nagad、GCash、Razorpay、SSLCommerz）并存，每个版本都有新增。
- **OwnPay 零交易手续费** —— 采用 AGPL-3.0 许可证。您只需支付网关自身的处理费用。
- **AGPL-3.0 许可，永久免费** —— 无功能限制，无许可层级，无电话回传遥测。完整源代码在 [GitHub]({{github}})。
- **插件可扩展** —— 无需修改核心代码即可添加网关、主题、插件和集成。拥有 60\+ 个钩子和完整的事件系统。
- **复式记账账本** —— 会计级别的财务追踪，具有 `bcmath` 驱动的精度、品牌隔离和内置对账功能。

## OwnPay 适用于谁？

| 受众 | 如何使用 OwnPay |
| :-- | :-- |
| **SaaS 企业** | 通过统一 API 接受订阅和一次性付款，同时将客户数据保留在内部。 |
| **市场平台** | 多租户支付编排 —— 每个卖家获得一个具有隔离资金和报告的品牌。 |
| **自由职业者和代理商** | 秒级创建支付链接，为客户白标结账页面，并在账本中追踪收入。 |
| **企业** | 本地部署或私有云部署，满足数据驻留要求，通过 Admin API 集成。 |

## 技术栈概要

<Columns>
  <Column>
    **运行时**

    - PHP 8.3\+（自定义框架，非 Laravel）
    - Twig 3 用于服务端模板
    - 前端使用原生 JavaScript
    - `bcmath` 用于所有货币计算
    - AES-256-GCM 用于个人身份信息加密
  </Column>
  <Column>
    **基础设施**

    - MySQL 8\+（架构、交易、账本）
    - Redis（缓存、会话、队列）
    - Nginx 或 Apache 配合 PHP-FPM
    - Docker Compose 支持
  </Column>
  <Column>
    **集成**

    - 3 个 REST API 层（Merchant / Mobile / Admin）
    - HMAC-SHA256 Webhook 签名
    - Android 伴侣应用用于短信验证
    - 插件 SDK，包含钩子、过滤器、事件
  </Column>
</Columns>
