OwnPay 位于您的业务与 123\+ 个支付提供商之间。当客户点击"支付"时，OwnPay 会将付款路由到正确的网关，在复式记账账本中记录结果，并向您的应用程序发送 Webhook——这一切都运行在您自己掌控的基础设施上。

## OwnPay 的独特之处 {#what-makes-ownpay-different}

- **自托管，完全的数据主权**——您的服务器、您的数据库、您的规则。客户个人身份信息（PII）在静态存储时使用 AES-256-GCM 加密。没有任何第三方能看到您的数据。
- **开箱即用的 123\+ 个网关**——国际处理商（Stripe、PayPal）以及区域领先者（bKash、Nagad、GCash、Razorpay、SSLCommerz），每个版本都会新增更多网关。
- **OwnPay 零交易费**——基于 AGPL-3.0 许可。您只需支付网关自身的处理费用。
- **AGPL-3.0 许可，永久免费**——没有功能限制、没有许可等级、没有回传遥测。完整源代码见 [GitHub](https://github.com/own-pay/OwnPay)。
- **可通过插件扩展**——无需修改核心代码即可添加网关、主题、附加组件和集成。提供 60 多个钩子和完整的事件系统。
- **复式记账账本**——会计级财务跟踪，基于 `bcmath` 的精确计算、品牌隔离以及内置对账功能。

## OwnPay 适合谁？ {#who-is-ownpay-for}

| 受众 | 如何使用 OwnPay |
| :-- | :-- |
| **SaaS 企业** | 通过统一 API 接受订阅和一次性付款，同时将客户数据保留在内部。 |
| **市场平台** | 多租户支付编排——每个卖家都获得一个拥有隔离资金和报表的品牌。 |
| **自由职业者和代理机构** | 几秒钟内创建支付链接，为客户提供白标结账，并在账本中跟踪收入。 |
| **大型企业** | 部署在本地或私有云上，满足数据驻留要求，并通过 Admin API 进行集成。 |

## 技术栈概要 {#technical-stack-summary}

<Columns>
  <Column>
    **运行时**

    - PHP 8.3\+（自研框架，非 Laravel）
    - Twig 3 用于服务端模板
    - 前端使用原生 JavaScript
    - 所有金额计算均使用 `bcmath`
    - AES-256-GCM 用于 PII 加密
  </Column>
  <Column>
    **基础设施**

    - MySQL 8\+（模式、交易、账本）
    - Redis（缓存、会话、队列）
    - Nginx 或 Apache，搭配 PHP-FPM
    - 支持 Docker Compose
  </Column>
  <Column>
    **集成**

    - 3 层 REST API（Merchant / Mobile / Admin）
    - HMAC-SHA256 Webhook 签名
    - 用于短信验证的 Android 配套应用
    - 带有钩子、过滤器和事件的插件 SDK
  </Column>
</Columns>
