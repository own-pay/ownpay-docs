OwnPay 使用基于角色的访问控制（RBAC）来决定每位员工可以查看和执行的操作。角色按品牌分配，因此同一个人可以在一个品牌上担任 Manager，而在另一个品牌上担任 Viewer。有关身份验证的详细信息，请参阅[登录和身份验证](/zh/security/login)。

## 内置角色 {#built-in-roles}

OwnPay 自带四种内置角色。v{{version}} 尚不支持自定义角色。

| 角色 | 范围 | 典型用途 |
| --- | --- | --- |
| **Super Admin** | 全局 - 所有品牌、所有设置 | 安装 OwnPay 的服务器所有者 |
| **Admin** | 按品牌 - 在分配的品牌内拥有完全访问权限 | 控制一个或多个品牌的业务经理 |
| **Manager** | 按品牌 - 可以管理付款和查看报表 | 处理日常交易的运营主管 |
| **Viewer** | 按品牌 - 对交易和报表的只读访问权限 | 仅需查看权限的审计员或会计 |

## 如何分配角色 {#how-to-assign-a-role}

1. 前往 **People** → **Staff**。
2. 点击该员工所在行的 **Edit**。
3. 从下拉菜单中选择**角色**。
4. 选择此角色适用的**品牌**。
5. 点击 **Save**。

角色会在员工下次加载页面时生效。如果他们当前已登录，请让他们刷新浏览器或退出后重新登录。

## 按品牌分配角色 {#per-brand-role-assignment}

同一位员工可以在不同品牌上担任不同角色。编辑员工时，您会看到所有品牌的列表，每个品牌旁边都有一个角色选择器。这样您就可以为某人授予品牌 A 的 Admin 权限，而在品牌 B 上仅授予 Viewer 权限。

<Warning>
  请勿将 Admin 或 Super Admin 角色授予只需查看报表的员工。请改用 Viewer 角色，并遵循最小权限原则。
</Warning>
