OwnPay 包含一个**内置的 Web 安装器**，会检查您的服务器配置、创建数据库架构并引导您创建主管理员账户。只需上传文件、访问域名，向导会处理其余工作 —— 无需命令行经验。

## 前提条件检查

<AccordionGroup>
  <Accordion title="系统要求" icon="list-check">
    | 组件 | 最低要求 | 推荐配置 |
    | :-- | :-- | :-- |
    | **PHP 运行时** | 8.3 | 8.3\+ |
    | **MySQL** | 8.0 | 8.0\+（或 MariaDB 10.4\+） |
    | **内存** | 512 MB RAM | 2 GB\+ RAM |
    | **磁盘** | 1 GB 可用空间 | 10 GB\+ SSD |
    | **Redis** | 可选 | 推荐用于缓存 |
  </Accordion>

  <Accordion title="必需的 PHP 扩展" icon="puzzle">
    确认以下扩展均已启用：`mbstring`、`pdo_mysql`、`gd`、`curl`、`zip`、`json`、`openssl`、`bcmath`、`intl`。

    在终端中运行 `php -m` 检查，或在您的托管面板中查看 PHP 信息页面。
  </Accordion>

  <Accordion title="文件夹权限" icon="folder">
    Web 服务器必须能够写入以下目录：

    - `storage/`（日志、会话、缓存、上传）
    - `public/assets/uploads/`（品牌 Logo、附件）
  </Accordion>
</AccordionGroup>

## 选择您的部署方式

<Tabs>
  <Tab title="共享主机" icon="world">
    适用于 cPanel、Plesk、DirectAdmin 和大多数共享主机提供商（Hostinger、Namecheap、SiteGround 等）。

    <Steps>
      <Step title="下载发行版">
        从 [GitHub Releases]({{github}}/releases) 下载最新的 `.zip` 文件。
      </Step>
      <Step title="上传并解压">
        通过文件管理器或 FTP 将 `.zip` 上传到您的 Web 根目录（`public_html/`）。直接解压到根文件夹中。

        <Warning>
          如果解压后创建了嵌套文件夹（如 `public_html/ownpay-v0.2.0/`），请将所有文件上移一级到 `public_html/` 并删除空文件夹。
        </Warning>
      </Step>
      <Step title="创建 MySQL 数据库">
        在您的托管面板中，创建一个新数据库和具有 **ALL PRIVILEGES** 权限的用户。记录主机名（通常为 `localhost` 或 `127.0.0.1`）。
      </Step>
      <Step title="将 PHP 设置为 8.3">
        打开 **Select PHP Version**（cPanel）、**PHP Settings**（Plesk）或 **PHP Version Selector**（DirectAdmin），选择 **8.3**。
      </Step>
      <Step title="启动 Web 安装器">
        访问 `https://yourdomain.com/install` 并按照 4 步向导操作：环境验证、数据库配置、架构导入和管理员账户创建。
      </Step>
      <Step title="设置定时任务">
        添加一个每分钟运行的 cron 任务：

        ```bash
        * * * * * php /home/your_user/public_html/public/index.php cron >> /dev/null 2>&1
        ```
      </Step>
    </Steps>
  </Tab>
  <Tab title="VPS（Nginx + PHP-FPM）" icon="server">
    完全控制技术栈。推荐用于生产环境。

    <Steps>
      <Step title="安装系统软件包">
        ```bash
        sudo apt update && sudo apt upgrade -y
        sudo apt install -y nginx mysql-server php8.3-fpm php8.3-mysql \
          php8.3-mbstring php8.3-curl php8.3-xml php8.3-zip \
          php8.3-gd php8.3-bcmath php8.3-intl \
          certbot python3-certbot-nginx
        ```
      </Step>
      <Step title="克隆并设置权限">
        ```bash
        cd /var/www
        sudo git clone {{github}}.git ownpay
        cd ownpay
        sudo chown -R www-data:www-data .
        sudo chmod -R 775 storage public/assets/uploads
        ```
      </Step>
      <Step title="创建 MySQL 数据库">
        ```bash
        sudo mysql -u root -p
        ```

        ```sql
        CREATE DATABASE ownpay CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
        CREATE USER 'ownpay'@'localhost' IDENTIFIED BY 'STRONG_PASSWORD';
        GRANT ALL PRIVILEGES ON ownpay.* TO 'ownpay'@'localhost';
        FLUSH PRIVILEGES;
        ```
      </Step>
      <Step title="配置 Nginx">
        创建 `/etc/nginx/sites-available/ownpay`：

        ```nginx
        server {
            listen 80;
            server_name yourdomain.com;
            root /var/www/ownpay/public;
            index index.php;
        
            location / {
                try_files $uri $uri/ /index.php?$query_string;
            }
        
            location ~ \.php$ {
                fastcgi_pass unix:/var/run/php/php8.3-fpm.sock;
                fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
                include fastcgi_params;
            }
        }
        ```

        启用站点、测试配置并重新加载：

        ```bash
        sudo ln -s /etc/nginx/sites-available/ownpay /etc/nginx/sites-enabled/
        sudo nginx -t && sudo systemctl reload nginx
        ```
      </Step>
      <Step title="配置 SSL">
        ```bash
        sudo certbot --nginx -d yourdomain.com
        ```
      </Step>
      <Step title="运行 Web 安装器">
        访问 `https://yourdomain.com/install` 完成设置向导。
      </Step>
      <Step title="设置定时任务">
        ```bash
        sudo crontab -u www-data -e
        ```

        ```bash
        * * * * * /usr/bin/php /var/www/ownpay/public/index.php cron >> /var/log/ownpay-cron.log 2>&1
        ```
      </Step>
    </Steps>
  </Tab>
  <Tab title="Docker" icon="box">
    适用于可复现环境的容器化部署。

    <Steps>
      <Step title="克隆并配置">
        ```bash
        git clone {{github}}.git && cd OwnPay
        cp .env.example .env
        # 编辑 .env 填入数据库凭据和密钥
        ```
      </Step>
      <Step title="启动容器">
        ```bash
        docker-compose up -d
        ```
      </Step>
      <Step title="运行迁移和种子数据">
        ```bash
        docker-compose exec app php bin/migrate
        docker-compose exec app php bin/seed
        ```
      </Step>
      <Step title="完成设置">
        访问 `http://localhost:8080/install` 配置管理员账户和第一个品牌。
      </Step>
    </Steps>
  </Tab>
</Tabs>

## 安装后验证

安装器完成后，确认一切正常工作：

<Steps>
  <Step title="验证仪表板加载">
    导航到 `https://yourdomain.com/login` 并使用您创建的管理员凭据登录。您应该能看到仪表板。
  </Step>
  <Step title="确认定时任务运行中">
    等待两分钟，然后检查系统日志中是否有定时任务条目。如果没有出现条目，请验证 cron 命令路径是否正确。
  </Step>
  <Step title="配置 SMTP">
    转到 **系统 \> 设置 \> 邮件设置** 并输入您的 SMTP 凭据。发送一封测试邮件确认投递。
  </Step>
  <Step title="启用双因素认证">
    转到 **我的账户** 并启用 2FA。强烈建议主管理员账户启用此功能。
  </Step>
</Steps>

## 故障排除

<AccordionGroup>
  <Accordion title="500 内部服务器错误" icon="alert-triangle">
    - 在 `.env` 中设置 `APP_DEBUG=true` 以查看实际错误消息。
    - 检查 `storage/logs/` 中的堆栈跟踪。
    - 确保 Web 服务器可以读取 `storage/` 和 `public/assets/uploads/`。
  </Accordion>

  <Accordion title="空白页面 / 白屏" icon="app-window">
    - 验证所有必需的 PHP 扩展已加载（`php -m`）。
    - 确认 `php.ini` 中 `memory_limit` 至少为 `512M`。
  </Accordion>

  <Accordion title="数据库连接失败" icon="database">
    - 在数据库主机字段中使用 `127.0.0.1` 代替 `localhost`。
    - 验证用户对数据库具有 `ALL PRIVILEGES` 权限。
    - 确认 MySQL 正在监听端口 `3306`。
  </Accordion>

  <Accordion title="权限被拒绝错误" icon="lock">
    - 在共享主机上，通过文件管理器将 `storage/` 设置为 `755` 或 `775`。
    - 在 VPS 上，运行 `sudo chown -R www-data:www-data storage/`。
  </Accordion>
</AccordionGroup>
