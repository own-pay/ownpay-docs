登录页面是 OwnPay 平台的主要安全关口。只有预先注册的员工和超级管理员才能登录。暴力破解防护和安全的会话管理可保护您的财务数据。

## 访问登录页面 {#access-the-login-page}

打开浏览器，导航到您的 OwnPay 域名，并在其后加上登录路径：

```text
https://your-domain.com/login
```

<Note>
  默认路径为 `login`，但您可以在[品牌设置](/zh/appearance/branding)中自定义它，通过隐蔽性获得额外的安全性。
</Note>

## 登录流程 {#login-process}

1. 输入您注册的**电子邮件地址或用户名**
2. 输入您的**密码**（区分大小写）
3. 可选择勾选 **Remember me** 以延长会话时长
4. 点击 **Sign In**
5. 如果已启用 2FA，请输入身份验证器应用中的代码（请参阅[双因素认证](/zh/security/two-factor)）

## 速率限制 {#rate-limiting}

OwnPay 会在多次登录失败后锁定账户。它通过两种方式跟踪失败次数：

- **按电子邮件和 IP 地址**：失败 **5** 次后，账户在该 IP 上被锁定。
- **按电子邮件跨所有 IP 地址**：失败 **15** 次（每 IP 阈值的三倍）后，账户在所有位置被锁定。

首次锁定持续 **5 分钟**。此后每一批失败都会使锁定时间翻倍（5、10、20 分钟），上限为 **30 分钟**。账户锁定期间的尝试也计为失败，因此持续尝试会重新开始并延长锁定，而不会让锁定自然到期。错误消息会显示剩余等待时间，例如 `Try again in about 10 minute(s)`。

每次尝试（包括锁定期间被拒绝的尝试）都会显示在管理侧边栏 **System** 下的 **Login Security Log** 中。您可以在该日志中点击 **Unlock Email** 或 **Unlock IP**，清除失败记录并提前解除锁定。

### 配置锁定阈值 {#configure-the-lockout-thresholds}

在 `.env` 文件中设置以下环境变量以更改默认值：

| 变量 | 默认值 | 描述 |
| --- | --- | --- |
| `MAX_LOGIN_ATTEMPTS` | `5` | 每个电子邮件和 IP 在锁定前允许的失败次数。按电子邮件的阈值是此值的三倍 |
| `LOCKOUT_DURATION` | `300` | 基础锁定时长（秒）。升级后的锁定时长不会超过 30 分钟 |

OwnPay 通过其运行时设置读取这两个值，因此同名键的运行时系统设置会覆盖 `.env` 中的值。缺失、为零、为负数或非数字的值将回退为默认值。

<Warning>
  来自同一 IP 的反复锁定可能表明存在暴力破解攻击。请查看 Login Security Log，并考虑在服务器层面封禁该 IP。
</Warning>

## 会话管理 {#session-management}

| 设置 | 默认值 | 描述 |
| --- | --- | --- |
| **会话超时** | 2 小时 | 会话过期前的空闲时间 |
| **"Remember me" 时长** | 30 天 | 勾选 "Remember me" 时延长的会话时长 |
| **并发会话** | 允许 | 多台设备可同时登录 |

会话存储在服务器端的 Redis 中。会话 Cookie 设置为 `HttpOnly` 和 `SameSite=Strict`，以防止跨站攻击。

## 并发会话 {#concurrent-sessions}

默认情况下，员工可以同时从多个浏览器和设备登录。您可以在[我的账户](/zh/security/my-account)中查看并终止活跃会话。

## 登录故障排除 {#login-troubleshooting}

| 症状 | 原因 | 解决方法 |
| --- | --- | --- |
| `Invalid credentials` | 电子邮件或密码错误 | 核实您的凭据。密码区分大小写 |
| `Account temporarily locked` | 失败尝试次数过多 | 停止重试并等待消息中显示的时间，或请管理员在 Login Security Log 中为您解锁账户 |
| `/login` 返回 `404 Not Found` | 已配置自定义登录路径 | 使用品牌设置中的正确路径 |
| 会话立即过期 | 服务器时钟不一致 | 检查服务器的 NTP 同步 |
