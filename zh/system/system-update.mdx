OwnPay 提供一键更新系统，让您的实例始终具备最新功能、安全补丁和错误修复。

## 检查更新 {#check-for-updates}

导航到 **System \> System Update**。该页面会显示您当前的版本以及是否有更新的版本可用。如果发现更新，将显示新版本号和变更摘要。

<Info>
  您也可以查看 [OwnPay GitHub 发布](https://github.com/own-pay/OwnPay)页面获取完整的更新日志。
</Info>

## 更新流程 {#update-process}

<Steps>
  <Step>
    点击 **Check for Updates** 查询更新服务器。
  </Step>
  <Step>
    如果有可用更新，请查看更新日志并点击 **Update Now**。
  </Step>
  <Step>
    OwnPay 会在应用更新前自动为当前安装（文件和数据库）创建完整备份。
  </Step>
  <Step>
    更新程序会下载并解压新版本、运行数据库迁移并清除缓存。
  </Step>
  <Step>
    更新完成后，您将被重定向到登录页面。
  </Step>
</Steps>

## 通过 ZIP 包更新 {#update-from-a-zip-package}

如果您的服务器无法访问更新服务器，或者您想应用某个特定版本，可以改为从您的计算机上传更新包。只有超级管理员能看到并使用 **Manual Update via ZIP Upload** 卡片。

更新包必须满足以下要求：

- 它是不超过 50 MB 的 `.zip` 文件。
- 它的根目录包含一个带有 `version` 字段的 `version.json` 文件。
- 除 `version.json` 外，所有文件都必须位于以下允许的目录之一：`src`、`config`、`templates`、`public`、`database` 和 `modules`。
- 它不包含符号链接，也不包含指向安装目录之外的路径。

<Steps>
  <Step>
    导航到 **System \> System Update**，然后滚动到 **Manual Update via ZIP Upload**。
  </Step>
  <Step>
    选择 `.zip` 文件并点击 **Validate & Preview Update**。OwnPay 会检查该更新包，如果任何要求未满足，会显示错误消息并拒绝该包。
  </Step>
  <Step>
    查看预览。预览会显示：
    - 目标版本
    - 您的当前版本
    - 该更新包是升级、相同版本还是降级
    - 文件名
    - 更新包大小
    - 签名状态
  </Step>
  <Step>
    点击 **Apply Update Now** 并确认。在更新完成之前请停留在该页面。更新成功后，OwnPay 会重新加载页面。
  </Step>
  <Step>
    OwnPay 会创建完整备份、进入维护模式、解压更新包、运行数据库迁移、清除缓存并运行健康检查。随后它会退出维护模式。
  </Step>
</Steps>

如果在备份创建之后任何步骤失败，OwnPay 会自动恢复备份并退出维护模式。更新历史会记录每次手动更新，包括上传的管理员和文件名。

<Warning>
  未签名的更新包会将签名状态显示为 **None (unsigned upload)**，并且仍然可以应用。请只上传您自己构建的更新包，或从 [OwnPay GitHub 发布](https://github.com/own-pay/OwnPay/releases)下载的更新包。包含 `signature.sig` 文件的更新包只有在签名验证通过时才会被应用。
</Warning>

## 更新后步骤 {#post-update-steps}

每次更新后，请执行以下检查：

1. **登录**并确认仪表板正常加载
2. 在[设置](/zh/system/settings)中**查看 Environment Info** 面板，确认新版本
3. 至少在一个品牌上**测试结账**，确保支付流程正常
4. **检查插件兼容性** - 在 OwnPay 主要版本发布后，部分插件可能需要更新

<Tip>
  OwnPay 会在更新后自动清除 Redis 缓存。如果您看到过时的数据，请手动刷新页面。
</Tip>

## 回滚步骤 {#rollback-procedure}

如果更新后出现问题，您可以回滚到之前的版本：

<Steps>
  <Step>
    导航到 **System \> System Update**。
  </Step>
  <Step>
    如果可以回滚，请点击 **Rollback to v**{{version}}。
  </Step>
  <Step>
    OwnPay 会恢复更新前创建的备份。
  </Step>
  <Step>
    在 Settings \> Environment Info 中检查版本以确认回滚成功。
  </Step>
</Steps>

<Warning>
  回滚会将文件和数据库恢复到更新前的状态。在更新与回滚之间处理的任何交易都会保留在数据库中 - 它们不会被撤销。
</Warning>

## 通过 CLI 更新 {#update-via-cli}

对于高级用户或自动化部署流水线，您可以从命令行更新 OwnPay：

```bash
php /path/to/ownpay/artisan update:run
```

此命令执行与 Web 界面相同的备份和更新流程。如果您有自己的备份策略，可使用 `--no-backup` 跳过自动备份。

<Info>
  有关主要版本之间的迁移指导，请参阅[迁移指南](/zh/resources/migration-guide)。
</Info>
